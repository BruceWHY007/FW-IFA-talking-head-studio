# 拆解与判定：哪句留脸、哪句盖 B-roll、盖什么

这是整个 skill 最值钱的一步。脚本只负责量和算，**判定由人（Claude）按本文件做**，写进两份文件：
`edits.json`（剪什么）和 `decompose.json`（每一镜是什么）。

---

## 一、先校对转写（transcript.json）

ASR 在专有名词上必错，而字幕错一个字就是事故。逐句改 `text`，`raw_text` 与 `chars` 不动（对齐用）。
改完加 `"_corrected": true`。改字不改时间：脚本会把改后的字对齐回原始逐字时间。

| 常见错 | 怎么判 |
|---|---|
| 公司名、人名、地名（复兴→复星、中英大厦→中银大厦、高智凯→高志凯） | 对照口径真源、机构官网；不确定的写进 `_校对备注` 和 facts.json 的 `pending` |
| 中英混说（奥运→All in、班德万→Band 1） | 按语境；英文词之间保留空格 |
| 同音数字与学制（中午→中五？中一？） | **不确定就标待确认**，交付说明里列出来，不要猜成定论 |
| 语气词 | 保留（字幕里显示），要剪的口癖写进 edits.json |

需要逐字口播稿时（`IFA口播选题库` 出的稿），以稿为准校对：稿是真值，ASR 只提供时间。

## 二、剪什么（edits.json）

```json
{
  "max_pause": 0.40, "keep_pause": 0.20, "head": 0.10, "tail": 0.45,
  "cut": ["s03:那么", "s08:那么"],
  "keep": []
}
```
- **长停顿**自动压：超过 0.40s 的压到 0.20s（不要压到 0，人会像被掐住）。按能量包络量，不靠转写。
- **句首口癖**（那么、然后、就是、其实）逐条写进 `cut`；句中的「这个」「那个」一般不剪，剪了容易断气。
- **重说**：analyze 标「疑似重说」的两句，删前一句（`transcript.json` 里该句加 `"drop": true`），留后一句。
- 先 `trim.py --dry-run` 看报告，⚠ 标的是「切点不在静音里」——剪完用 `--verify` 把剪后人声再转写一遍逐字比对；相似度 ≥0.9 且差异只是 ASR 同音错才算剪干净。
- 剪掉的比例通常 8–15%。超过 20% 说明原片问题大，先跟用户说。

## 三、每一句是什么：七类镜头

| 代号 | 是什么 | 什么句子给它 | 参考片 |
|---|---|---|---|
| **A** 人脸 | 原片，不盖 | 钩子、观点、判断、转折（「更绝的是」）、反问、情绪、自我介绍、号召；**有手势有表情的句子**（analyze 标「A·宜留」） | 44% |
| **B** B-roll | 满幅画面＋字幕移到中部 | 现象、事实、名词（机构、地点、行业）、数字句；**画面平淡**的句子（「A·可遮」）；**画面有问题**的句子（「需遮」：失焦、低头看稿、卡壳） | 44% |
| **S** 本人素材 | 出镜人自己的实拍 B-roll | 第一人称经历：「我帮客户……」「我们团队……」「我每天……」 | 8% |
| **P** 照片卡 | 真实照片／截图做卡，压在虚化人脸上，刊头不撤 | 真实人物、机构、新闻、文件、App 界面第一次出现 | 5% |
| **G** 大字／数字卡 | 一个词或一个数，说到它的那一帧揭开 | 全片题眼（1 个词）＋最关键的数字（1–2 个）。**一支片子 ≤3 张** | 参考片没有，本 skill 的升级 |
| **PH** 手机里的她 | 她本人的原片放进一部手机（背景是她虚化） | 「多出镜」「录视频」「发到视频号」这类讲拍摄本身的句子；没有本人生活素材时代替 S | 第 2 轮评审：用外国女士在手机里出镜＝替身，改成她自己 |
| **I** 信息卡 | 原文／对比／清单／时间线／柱图（材质按风格包，见 `04` §三） | 引报告指引原文、两个以上数字、「第一第二第三」、时间先后——**字幕扛不住、B-roll 又配不准的信息** | 参考片用满屏字卡；本 skill 按内容换卡型，是每支不重样的第三层 |

判定顺序（逐句过）：
```
这句画面有问题吗（需遮）？ ── 是 → B（或删句）
这句是钩子／观点／转折／情绪／号召吗？ ── 是 → A（有手势的更要留）
这句是第一人称经历、且有本人素材吗？ ── 是 → S
这句第一次点出真实人物／机构／文件吗？ ── 是 → P（有真图才用；没有就 B，信息由字幕扛）
这句是全片题眼词或关键数字吗？ ── 是 → G（≤3 张）
这句有两个以上数字、几件事、几个时间点、或在引原文吗？ ── 是 → I（选卡型；数据要有 source）
其余：事实、名词、现象 → B
```

### 节奏线（build.py 会检查并报警）

| 项 | 线 | 为什么 |
|---|---|---|
| 开场 | 前 3–4 秒是脸＋名字条 | 先建立「谁在说」 |
| 人脸连续 | ≤8.5s | 再长就闷；中间找一句事实、名词或动作盖 B |
| 单条 B | 1.6–6.5s | 短于 1.6s 读不完字幕；长于 6.5s 拆两条 |
| 人脸占比 | 35–60% | 太低像幻灯片，太高像监控录像 |
| 结尾 | 号召句回到脸 | 关注／下期是人对人说的话 |
| G 卡 | 只盖那个词＋前面 ≤1 秒的引子 | 10-18 实测：盖整句「整个的，可以用两个字吧，布局」= 2.7 秒干等，验收判冻结；只盖「两个字吧，布局」就活了。数字卡同理，并压一层在动的实景 |
| 人脸连续 | ≤8.5s（景别变化不算换画面） | 第 1 轮评审：一次推镜撑不住 12.5 秒的人脸 |

### 跳切换景别（自动）

剪口癖、压停顿会在人脸镜头里留下跳切。被 B-roll 盖住的不管；露在外面的，build.py 在每个跳切处在
1.0 与 1.08 两档景别之间切换（以人脸为中心推），读作有意的剪辑。原片人脸占画面宽度 >45%（自拍式近景）时不推（`punch_scale` 写 1.0）。

## 四、decompose.json 写法

```jsonc  // 带注释的示意：真正的 decompose.json 里不能有 // 注释
{
  "style":   "A",                       // A／B／C／K1／K2／K3（或 editorial／glass／kinetic／evidence／diagram／brand），先跑 suggest_style.py 看推荐
  "account": "账号名（同一账号沿用主题、封面形式自动错开）",
  "theme":   "维港青",                   // themes.json 里的名字；不写＝沿用该账号上一支，没有就琥珀金
  "title":   {"series": "系列名（≤10 字）", "episode": "本期标题：用原话里的硬事实做钩子（孩子进了 Band 1 · 团队 20 人）"},
  "cover":   {"form": "auto", "kicker": "2–4 字小标", "title": ["第一行 ≤8 字", "第二行 ≤9 字"],
              "number": {"value": "2.9", "unit": "万亿美元"}, "versus": {"left": {"label": "香港", "value": "10.7%"}, "right": {"label": "瑞士", "value": "7.6%"}, "win": 0},
              "quote": {"text": "一句原话", "source": "出处"}},   // form：title／number／versus／quote／auto（在写了数据的几种里挑，和上一支错开）
  "speaker": {"name": "姓名", "latin": "英文名（可空）", "lines": ["身份一 ≤12 字", "身份二"], "hold": 4.0},
  "end":     {"from": "下期预告开始的那句原话", "kicker": "下期预告", "line": "第一行\n第二行", "cta": "关注我 · 下期见"},
  "captions": {"highlight": ["关键词（会在说到时变金画线）"], "max_chars": 15},
  "chapters": [{"title": "布局"}, {"from": "从3月份开始", "title": "家庭"}],
  "emphasis": [{"at": "All in香港", "scale": 1.14, "why": "全片最硬的判断"}],
  "lib_label": "示意画面 · AI 生成",   // 素材库角标文案
  "footer":  "paper",                   // paper（默认，整页纸）／fade／plate：底部怎么做，见 04（发抖音改 fade 或 plate）
  "tags": [{"cover": "我背后就是中银大厦", "text": "身后 · 中银大厦", "point": [0.13, 0.22]}],
  "shots": [
    {"id": "B01", "type": "B", "cover": "原话起…原话止", "pick": "stock:st_central3", "in": 1.0, "focus": 0.5, "move": "pan-l",
     "tag": "中环", "need": "画面要什么", "why": "为什么这句给 B", "gen_prompt": "（可选）生成提示词"},
    {"id": "B02", "type": "B", "cover": "把香港的这个事业…都布局好了", "pick": "lib:L005", "in": 2.0, "focus": 0.3,
     "split": {"pick": "lib:L034", "in": 5.8, "focus": 0.5, "at": "家庭", "labels": ["事业", "家庭"]}},
    {"id": "G01", "type": "G", "cover": "可以用两个字吧…布局", "figure": {"kind": "word", "value": "布局", "label": "这几个月 · 两个字", "at": "布局"}},
    {"id": "G02", "type": "G", "cover": "发展了有二十个人", "pick": "lib:L028", "figure": {"kind": "number", "value": "20", "unit": "人", "label": "复星 · 团队", "at": "二十个人"}},
    {"id": "P01", "type": "P", "cover": "……", "image": "assets/照片.jpg", "credit": "图源：xxx"},
    {"id": "I01", "type": "I", "cover": "差在增速…瑞士7.6%", "info": {"kind": "compare", "title": "规模打平，差在增速",
      "items": [{"label": "香港", "value": "10.7%", "note": "2025 年增速", "at": "十点七"}, {"label": "瑞士", "value": "7.6%", "note": "2025 年增速", "at": "瑞士"}],
      "win": 0, "source": "BCG《2026 全球财富报告》"}},
    {"id": "I02", "type": "I", "cover": "第一，钱从哪来…通道在变宽", "info": {"kind": "list", "title": "三件事接上了",
      "items": [{"t": "钱从哪来", "d": "约六成来自内地", "at": "第一"}, {"t": "有地方去", "d": "374 亿美元新股募资", "at": "第二"}, {"t": "通道变宽", "d": "额度提到 300 万", "at": "第三"}]}}
  ]

```
- **核心信息必须有包装**：一条片子里，凡是「观众会记下来／会截图／会拿去问人」的东西（关键数字、专有名词、结论句），都要有对应的卡或字幕强调；
  政策、解读、对比、盘点这类信息密度高的内容，**4–8 张卡的密度是正常的**，不要停在「3 张卡就够」。
  判据：把字幕全遮掉，只看卡，能不能说出这条片子的三件事；说不出来就是包装不够。
- **信息卡不许「只有标题」**：卡片切进来时，条目要么 0.4 秒内一起出完，要么先铺一层 18% 的灰骨架；
  一条卡在屏超过 0.6 秒还只有一个标题，就判空卡。
- **cover 用剪后原话做锚点，不写秒数**。「起…止」各取几个字；只写一段＝只盖那一段。标点空格不参与匹配。
- 镜头边界自动落在**开口帧**（跳过标点）；太短的镜头往前长到更早的开口帧，不往后长。
- `pick`：`lib:L008`／`stock:名字`／`gen:B07`／`file:相对路径`；空着＝渲空片格。素材库文件挪了位置：`broll_index.py <工程> --relink <新目录>`。
- `move`：`push`／`pull`／`pan-l`／`pan-r`／`hold`，按画面选（见 `04` §三）。
- `focus_y`（可选，默认 0.5）：竖向取景，0 顶、1 底（浪花、桌面这类在画面下部的动作）。
- `split.left_focus`（可选，默认 0.5）：分屏后左半边取原画哪一段，0＝最左；主体在原画左缘就给 0.1。
- `grade_extra`（可选）：单镜补光，追加在统一调色后面，例 `"eq=gamma=1.15:brightness=0.02"`；只给明显偏暗的素材用。
- `chapter_rise`（顶层，可选，默认 false）：章节第一镜从接缝升起；默认硬切。
- `split`：两件并列的事用分屏，`at` 是说到第二件事的那个词。
- `figure.at`：大字或数字在说到它的那一帧揭开。**G 卡只盖那个词＋前面 ≤1 秒的引子**（build.py 对超过 1.2 秒的报警）；**字落下后至少完整可读 1.3s**（build.py 自动把出点延到那之后的开口帧，必要时推后一镜的入点）。数字卡给 `pick` 压一层在动的实景（自动虚化、自动挂角标），停留不冻住。
- `outro`：落版秒数（默认 1.3）；`end.cta` 会在落版时打在字幕带。
- 删掉一句（`drop`）后重跑 build，看「人脸连续」警告：删句会改变节奏。
- `chapters`：4–6 章；第一章不写 `from`。每章第一个 B-roll 自动用「升起」转场。
- `emphasis`：全片 1–3 处，只给最硬的判断或情绪落点。
- `tags[].point`：原片里真有那样东西时，画指引线指过去（画面窗内 0–1 坐标，看风格帧量）。
- `lib_label`：用户素材库的来源标签（AI 生成的写「示意画面 · AI 生成」）；免费素材自动标「示意画面 · Pexels」。
- `why`：每一镜写一句理由，给评审和接手的人看。
- `info`（I 镜头）：`kind` 五选一（quote／compare／list／timeline／chart，字段见 `04` §三）；条目的 `at` 是说到它的那几个字，没写就按顺序每 0.4s 一条；
  quote 的 `hl` 是重点词、`hl_at` 是说到它的原话。**每张卡在 facts.json 的 `cards` 里登记一次**（`{"I01": {"kind": "数据", "source": "…"}}`），否则 qa 报「信息卡没登记」。
  信息卡在屏时字幕不高亮（卡就是这一刻的重点）。一支片子 I 卡 1–3 张、和 G 卡合计 ≤5 张，多了就成了 PPT。
- 同一条原片出几个风格的版本：另存 `decompose_K2.json`，`make.py <工程> --decompose decompose_K2.json --out 样片_K2.mp4 --no-register`。

### 判定时额外守的四条（第 1 轮评审栽出来的）

1. **不用陌生人的正脸冒充当事人或其家人**。讲「我家孩子」「我的客户」时，没有本人素材就用空间、物件、背影；侧脸也不行。
2. **AI 素材里有可读的假中文（白板、招牌、屏幕）或画出来的 logo，一律不用**。中文观众一眼看出是 AI，品牌 logo 只用源文件。
3. **原片里有真东西，就别先放一条示意的假东西**（她身后就是中银大厦，不要先插一条 AI 写字楼）；地点句要 B-roll 就用真实地点的实拍。
4. **屏上转述不拼接、不加绝对化说法**：「来港这半年」把孩子 3 月来港安到她身上、「只做了一件事」是新加的绝对说法——这类都是改意。刊头和封面优先用原话里的硬事实。

## 五、10-18 测试片的判定（作为例子）

原片：一位理财师在复星中环办公室的近景自拍口播，93 秒，单条无 NG，背景窗外是中银大厦。

| 我背后就是中银大厦 | **A＋标注签** | 中银大厦就在她身后，原片就是证据 |
| 趁着有时间，交代一下 | A | 转场句 |
| 两个字吧，布局 | **G 方格「布局」** | 题眼 |
| 花了几个月的时间 | A | |
| 把香港的这个事业 | B 复星财富前台 | 事业＝复星 |
| 和家庭，都布局好了 | B 住宅窗里一家人 | 家庭 |
| 3 月开始带孩子来香港读书 | B 妈妈牵孩子（免费素材） | 行动 |
| 我自己的事业……All in 香港 | A | 最强的判断句，必须看脸 |
