> 任何一行都可以留空，由制作方决定，但要在行尾写下选择和一句理由。冲突时以本 brief 为准。

| 项 | 填写 | 说明 |
|---|---|---|
| 类型 | 真人口播成片（固定） | 原片是一条真人对镜头口播；本 skill 不做无原片的动画解说 |
| 主题 | | 这一期讲什么，一句话 |
| 观众 | | 谁在看、他们在乎什么（例：在内地、考虑香港身份的家长） |
| 结尾 | | 最后一秒观众要感受到什么、知道什么、去做什么 |
| 画幅时长 | 9:16 1080×1920，时长跟口播走（剪完通常是原片的 75–90%） | 要横版另说，横版重新构图，不裁切 |
| 帧率 | 30 | 真人实拍跟原片走 |
| 风格包 | A 分带刊物（个人近况）／B 雾金玻璃（活动品牌）／C 港刊大字（热点观点）／K1 证据桌（政策原文）／K2 图解（数字清单）／K3 IFA 品牌刊（平台招募） | 留空＝跑 suggest_style.py 按内容推荐；拿不准就 gallery.py 出目录挑；logo 只用源文件 |
