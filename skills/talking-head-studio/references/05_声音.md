# 声音：人声是主角，配乐只做底，音效只给真发生的事

```bash
python3 scripts/mix.py <工程> --bgm 配乐.mp3 --bgm-in 13.1 [--bgm-db -12] [--no-sfx]
```

## 一、人声（原片原声，不换配音）

剪辑阶段已经把人声和画面按同一张 EDL 剪好（按帧号与采样号剪，48k÷30＝每帧 1600 个采样，整片零漂移），
口型天然对齐。mix.py 只做三件事：75Hz 低切、轻降噪（`afftdn nr=6`，房间底噪约 −48 dB 时刚好）、温和压缩（2.5:1）。
不做激进降噪——办公室环境声是「真人在现场」的一部分，抠干净了反而假。

## 二、配乐

- **来源**：用户给的优先；没有就用户自己在 ElevenLabs Music／MiniMax Music（RunningHub）生成。提示词里不写品牌、不写艺人名。只用能商用的。
- **选段**：从配乐里截一段和片长相当的（`--bgm-in`），首 1.2 秒淡入、尾 2.8 秒淡出。宁可挪起点，不为音乐改剪辑。
- **电平**：基础 −12 dB，再由人声做 sidechain 自动压（说话时压下去，句间 0.4 秒缓回来）。
- **判据**（qa 会量）：人声频带（300–3400Hz）里，说话时人声比配乐高——中位 ≥20 dB，低的 10% ≥12 dB。
  10-18 测试片：中位 23.9、低 10% 17.2。低于判据＝配乐糊人声，降 `--bgm-db`；高太多（中位 >30）＝配乐听不见，升。
- 父 skill 的配乐判据仍然适用：有人声时配乐中频（250–4000Hz）占比 ≤0.20，选曲时先量。

## 三、音效（代码合成，无版权问题）

只给画面里真发生的事，B-roll 硬切不配（人声是连续的，切画面不该有声音）：

| 事件 | 音 | 频段 | 电平 |
|---|---|---|---|
| 名字条画线、下期预告出现 | 一声很轻的「嗒」 | 2–6 kHz | −26 dBFS |
| 大字／数字揭开 | 0.5 秒气流上扬，落点对准揭开那一帧，接一记 60–90Hz 低频 | 0.4–5 kHz ＋ 低频 | −23 dBFS |
| 照片卡落位 | 一口很短的气 | 0.8–3 kHz | −30 dBFS |

事件时间来自 timing.json（build.py 生成，大字卡的音效钉在 `revealFrom` 上）。一支 80 秒的片子 3–6 个音效足够。

## 四、响度

两遍 loudnorm 到 **−14 LUFS、真峰值 ≤ −1.5 dBTP**，再过一道限幅。另外导出 `music_only.wav`（配乐＋音效、不含人声，与成片同一增益关系），方便后期换配乐或交给剪辑师。


## 避让不抽吸（10-22 第 5 轮评审）
避让的键＝人声＋延后 180ms、360ms 各一份（amix），`sidechaincompress` 释放 900ms。句间 0.3–0.6s 的小停顿里配乐不抬头，长停顿才慢慢回来。实测同一段音频：气口抬头 35 次→0 次，人声高出配乐低 10% 仍 ≥12 dB。
