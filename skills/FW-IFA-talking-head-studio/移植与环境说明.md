## 一、这个 skill 交付什么

**输入**：一条真人对镜头口播原片（手机或相机拍，竖版或横版都行）＋少量信息（出镜人姓名身份、系列名、有没有素材）。
**输出**：一支不用再剪、不用再包装、不用再找素材的竖版成片（1080×1920、30fps、−14 LUFS），以及一整套可追溯的工程文件。

整条线做的事：转写校对 → 逐句拆 A-roll（哪句留脸、哪句盖 B-roll、盖什么信息）→ 剪口癖、删重说、压停顿 →
B-roll 三路来源（用户素材库挑／免费素材库找／AI 生成接口，生成默认关闭）→ 风格包包装（刊头、字幕、名字条、标注、分屏、大字卡、下期预告）＋跟着说话走的动态 →
配乐自动避让与响度 → 27 项量化验收＋接缝检查 → 派独立评审子代理审片，改到「可以发布」。

结构基准是一支参考成片（复星财富 IFA 财经口播《全球抢钱大逃杀（上）》，拆解在 `references/01`）；设计借 IFA App 展示片的「视觉带与文字带分开」。

## 二、质量标准（用户给的 brief，原则全部保留）

用户在建 skill 时给了一份「动效导演」级的总要求，这是本 skill 的**底线，不是上限**。下表把每一条映射到 skill 里的落点，接手时任何一条都不能丢。

| 要求（原文要点） | 在本 skill 里怎么落实 | 在哪 |
|---|---|---|
| **角色**：动效导演兼创意技术人；设计、动画、配乐、质检全部用代码完成；拿同类最好的作品比，能摆在一起不露怯才算做完 | 全流程脚本化（Python＋Remotion）；每支片子对标参考片；独立评审子代理做「导演审片」 | `SKILL.md`、`references/06` |
| **brief 字段**（类型、主题、观众、结尾、时长画幅、帧率、品牌、事实来源、素材、风格、声音、自主度、工具链、落版），留空的由制作方决定并写理由 | 口播版 brief 模板，类型固定为「真人口播成片」 | `template/brief.md` |
| **explainer 模式**：只讲一个因果；画面文字不重复旁白 | 口播片的对应：A/B 判定；大字卡上与大字相同的字幕自动删 | `references/02`、`build.py` |
| **素材**：真 logo 用源文件不重画；截图不当静止板子；生成图只当参考；参考作品只学原则不照搬 | AI 画出来的 logo、假中文一律不用；照片卡用真图并写图源；参考片只拆结构与规律 | `references/02 §四`、`03 §四` |
| **craft 1**：第一帧是完成画面，钩子在第一秒 | 封面帧（画面窗里两行宋体大标题，停 1.2s），刊头用原话里的硬事实 | `packs/editorial.tsx` Cover |
| **craft 2**：一个物体贯穿全片 | 一条 2px 金线：刊头、接缝、名字条、标注签、关键词下划线、大字卡都从它开始 | `references/04 §一` |
| **craft 3**：转场由内容完成，硬切只切在节拍上 | 剪辑点＝开口帧；章节第一镜从接缝「升起」；分屏在说到第二件事时打开 | `build.py`、`Film.tsx` |
| **craft 4–5**：主运动＋错开的次级运动；速度变化、不用线性缓动 | 统一缓动表（进场快起慢收、离场慢起快走、推拉 S 曲线）；名字条、标注逐行错开揭开 | `theme.ts`、各 pack |
| **craft 6**：每个动作有看得见的结果 | 关键词变金＋下划线、方格涨光后字落格、指引线落到实物上 | `references/04 §三` |
| **craft 7**：文字是动效不是字幕；每词约 0.3s、最少 0.7s；画面太花垫底板；画面说明白的就删字 | 字幕每张 ≥0.7s；分带版式字永远不压画面；画面已说的字幕自动删 | `qa.py`、`build.py` |
| **craft 8**：景别与版式要变化，版式不重复 | 五类镜头（人脸／B-roll／照片卡／大字卡／手机里的她）＋分屏；跳切换景别 | `references/02 §三` |
| **craft 9**：停留镜头也要呼吸，任何东西不冻住；快速运动加模糊 | 人脸 3% 呼吸；验收「任何静止段 ≤0.5s（只量画面窗）」 | `Film.tsx`、`qa.py` |
| **craft 10**：只在讲空间关系时用 3D | 本 skill 不用 3D | — |
| **craft 11**：每个效果都要有理由；不要装饰粒子、泛滥渐变、素材库故障效果 | 动态语汇表每一项写明「什么时候用」；评审专查「为动而动」 | `references/04 §三`、`06` |
| **audio**：先做声音；音乐压低；音效只给真发生的事；有对白压音乐；−14 LUFS、真峰值 ≤ −1 dBTP；另出纯音乐版 | 原声即主线；配乐 sidechain 避让，判据「人声频带高出配乐，低 10% ≥12 dB」；音效代码合成、只 4–6 处；混音峰值 −2 dBTP 给编码留余量；出 `music_only.wav` | `mix.py`、`references/05` |
| **build**：所有内容是代码、同一条时间线、字体素材本地固定、逐帧渲染、密钥放环境变量、正式开工前渲 3–5 秒测试、数值是帧号的函数、无定时器无随机 | `timing.json` 单一真源；字体子集编进代码包；`render.py --test` 先渲 5 秒；密钥只读环境变量 | `build.py`、`render.py` |
| **workflow**：锁事实 → 研究参考 → 构思 2–3 个方向 → 分镜 ◆ → 风格手册与三张风格帧 ◆ → 声音 ◆ → 构建与评审循环 → 交付 ◆ | 对应 `SKILL.md §1` 十二步；风格方向三选一（`references/04 §四`）；◆ 处 gated 模式停下给人看 | `SKILL.md` |
| **critic loop**：做的人不评自己；每次整片渲染后派全新评审：抽帧、静音解读、同步检查、事实核查、导演审片；修最大的、重渲、再派新评审查全部；记 ledger | 评审提示词模板固定；每轮写 `qa/评审_第N轮.md`；`ledger.md` 记改前改后数字 | `references/06 §二` |
| **quality bar**：时长尺寸帧率准确；首帧完成；冻结限制；对比度 ≥4.5:1；安全区；同步 ≤1 帧；响度；静音能读懂；每条说法有出处；生成内容有标注 | `qa.py` 27 项＋`seams.py` 接缝图；facts.json 出处表；AI／示意角标 | `references/06 §一` |
| **deliverables**：成片、纯音乐版、10–20 帧缩略图、brief、facts、风格手册、timing、ledger、验收结果、待人确认清单 | 全部自动生成或模板化 | `SKILL.md §7` |

## 三、系统环境

### 3.1 需要什么（三个系统通用；`setup.py` 逐项检查，缺的按系统装）

| 项 | 要求 | 谁来装 | 说明 |
|---|---|---|---|
| Python | 3.9+；库 numpy、Pillow、fontTools；非 macOS 另加 opencv-python-headless（人脸检测） | 需要先有 Python；库由 `setup.py` 用 pip 装（清华镜像／官方源，先测哪个通） | 脚本刻意不用 3.10 语法 |
| ffmpeg／ffprobe | 带滤镜 loudnorm、sidechaincompress、acompressor、afftdn、alimiter、minterpolate、colorspace、ebur128、boxblur，和 H.264 编码器 | macOS：`brew install ffmpeg`；Windows／没有包管理器时：`setup.py` 自动下静态版 6.1.1 放到 `~/.cache/ifa-koubo/bin`（脚本自己认这个目录，不用改系统 PATH） | 中间文件编码：macOS 用 VideoToolbox，其他系统 libx264 veryfast |
| Node.js | ≥18 | macOS：`brew install node`；Windows 没有时 `setup.py` 自动下便携版到 `~/.cache/ifa-koubo/node` | 只用于 Remotion |
| Remotion 运行时 | 4.0.484（react 19.2.7），锁在 `runtime/package.json` | `setup.py` 在 `runtime/` 里 `npm install`（npmmirror／npmjs 先测哪个通、哪个快；15 分钟时限） | 约 330MB；所有工程共用一份；**必须在本机装**（合成器是分平台的二进制，不能把 macOS 的 node_modules 拷给 Windows） |
| 无头浏览器 | chrome-headless-shell 149.0.7790.0（Remotion 钉的版本） | `setup.py` 从 npmmirror 下同一版本，放到 Remotion 找的位置 `runtime/node_modules/.remotion/` | Windows 包 113MB。**不装的话 Remotion 首次渲染会自己去 storage.googleapis.com 下，国内不通，会一直等到超时** |
| whisper.cpp | `whisper-cli` | macOS：`brew install whisper-cpp`；Windows：`setup.py` 下官方发布的 `whisper-bin-x64.zip`（4MB）到 `~/.cache/ifa-koubo/bin` | Linux 要自己编译或用发行版的包 |
| 转写模型 | `~/.cache/whisper-cpp/` 下的 ggml 模型 | 已有 `ggml-small.bin` 就用它；没有时 `setup.py` 从 hf-mirror 下量化版 `ggml-small-q5_1.bin`（190MB，断点续传） | 11-10 实测：量化版与原版 small（487MB）转写结果基本一致，纯 CPU 快约四成。要原版：`setup.py --model small`；用别的模型：环境变量 `WHISPER_MODEL` |
| 字体 | 思源宋体 SC Heavy／SemiBold、Bodoni Moda（OFL，随包 47MB） | 随包 | 黑体用系统的：macOS 苹方／Windows 微软雅黑／Linux Noto Sans CJK |
| macOS 专有 | Swift（Xcode 命令行工具）：Vision 人脸检测与画面文字识别 | 首次用到时自动编译到 `~/.cache/ifa-koubo/` | 其他系统：人脸检测用 OpenCV；**画面文字识别没有**，候选图不标「字」、qa「B-roll 可读文字」跳过，要人看 |
| 可选 | `PEXELS_API_KEY`／`PIXABAY_API_KEY`（免费）；`firecrawl` CLI（抓 Pexels 搜索页，需账号额度） | 人 | 都没有时免费素材只剩 Coverr／Mixkit |

已验证的机器：Apple M3 Pro／18GB／macOS 26.5（82 秒成片整片渲染约 105–110 秒，并发 3）。Windows 上的安装路径 11-10 只在 macOS 上验证过下载源、压缩包结构和脚本逻辑，**还没有在真机 Windows 上跑通过一遍**——第一次在 Windows 上装，把 `setup.py` 的完整输出留下来。

## 四、安装与自检

```bash
# 1. 拿到技能文件夹（任选其一）
#    npx skills add BruceWHY007/FW-IFA-talking-head-studio -g --agent <你的 Agent>
#    或直接把整个文件夹拷到 Agent 的技能目录（Claude Code：~/.claude/skills/；Codex：~/.codex/skills/；WorkBuddy：~/.workbuddy/skills/）
#    GitHub 拉不动：让同事把技能文件夹打成 zip 发过来，不要带 runtime/node_modules

# 2. 安装（只需要先有 Python 3.9+；可以反复跑，装过的跳过）
python scripts/setup.py            # macOS 写 python3
#    最后一行是 [setup] OK 才算好。中途停了：照「→」后面的做，多数重跑一次就能续上（大文件断点续传）

# 3. 验证（渲一帧，证明 打包→无头浏览器→视频解码→文字 这条链是通的）
python scripts/setup.py --check --smoke

# 4. 国内网络还是下不动：用离线包
#    有网的人做：python scripts/setup.py --pack <某个目录> --target win   （约 400MB：浏览器、ffmpeg、Node、whisper、模型）
#    装的人用：  python scripts/setup.py --offline <那个目录>
```

macOS 上 `setup.py` 不替你装系统软件，缺什么它会打印命令：`brew install ffmpeg whisper-cpp node`。
Windows 上不需要管理员权限、不改系统 PATH：它下的工具都在 `~/.cache/ifa-koubo/`，脚本自己认。

**给 Agent 的安装规矩**：
- 只跑 `setup.py`，不要自己拼 `npm install`、`curl` 去下模型和浏览器——默认源在国内不通，会卡到超时。
- `setup.py` 自己有时限；它没结束就等它结束，不要并行再起一个。结束后没出 `[setup] OK`，把「还缺这些」原样报给用户。
- 工程目录里永远不跑 `npm install`（node_modules 是指向技能 `runtime/` 的链接）；Remotion 版本只在 `runtime/package.json` 改，升级后先 `setup.py --smoke`。
- 旧命令 `bash scripts/setup.sh`、`bash scripts/doctor.sh` 还在，只是转调 `setup.py`。

## 五、全流程（每一步：命令、产物、谁来判断）

`工程` 指工程目录（不要建在桌面根目录）。「判断」栏：**脚本**＝自动；**AI**＝接手的 AI 按规则判断并写文件；**人**＝必须给用户看或由用户提供。

| 步 | 命令 | 产物 | 判断 | 规则在哪 |
|---|---|---|---|---|
| 0 自检 | `python3 scripts/setup.py --check` | — | 脚本 | 本文件 §三、§四 |
| 1 建工程 | `python3 scripts/new_project.py 原片 工程 --title 系列名` | brief.md、facts.json、project.json、ledger.md、remotion/ | 脚本；brief 由 AI 填、缺的问人 | `template/brief.md` |
| 2 导入转写 | `python3 scripts/ingest.py 工程 --prompt "专有名词"` | work/aroll.mp4（30fps CFR 竖版，HDR 转 SDR）、voice.wav、transcript.json、energy.json、sheet_2s.jpg | 脚本 | — |
| 3 校对 | 改 `transcript.json` 每句 `text`，加 `"_corrected": true` | 校对后句表＋`_校对备注` | **AI**（不确定的字列进 facts.pending 问人） | `references/02 §一` |
| 4 拆 A-roll | `python3 scripts/analyze.py 工程` | work/aroll_sheet.jpg（逐句一格：人脸朝向、清晰度、手势、语速、口癖、疑似重说） | 脚本出标签，**AI** 看图判 | `references/02 §三` |
| 5 剪什么 | 写 `edits.json`；`python3 scripts/trim.py 工程 --dry-run` 看报告；`trim.py 工程 --verify` 落盘并复核 | work/aroll_cut.mp4、audio/voice_cut.wav（逐帧同长）、work/transcript_cut.json、work/edl.json | **AI**（⚠ 切点列给人听） | `references/02 §二` |

## 七、规范汇总（每条都是实测或评审栽出来的）

**判定**（`references/02`）：钩子／观点／转折／情绪／号召留脸；现象、事实、名词、数字盖 B-roll；第一人称经历用本人素材；真实人物机构用照片卡；题眼词与关键数字用大字卡（≤3 张，只盖那个词＋≤1 秒引子）；讲「录视频、出镜」用「手机里的她」。开场 3–4 秒是脸＋名字条；人脸连续 ≤8.5s；B-roll 单条 1.6–6.5s（F 包 ≤9s）；人脸占比 35–60%（F 包完整版 40–78%）。

**素材**（`references/03`）：看图挑不看文件名；信息对得上、不误导、竖版能用、有动作、够长；**不用陌生人正脸冒充当事人或家人**；**AI 素材里有可读假中文或画出来的 logo 不用**；原片里有真东西就别先放示意的假东西；24/25fps 逐帧铺进 30fps；截取段不跨素材内部剪辑点；AI／示意画面挂角标。

**设计**（`references/04`、`11`）：七套风格包，默认 F 满幅讲述（A 分带刊物＝字永远不压画面）；宋体只给标题与大字、字幕苹方、数字 Didot、小标签细体大字距；纸上金色文字用铜金 `#7F5631`；带字的层零 transform；零描边零投影；数字不 count-up；任何静止段 ≤0.5s；剪辑点＝开口帧；动态都要说得出在交代什么。

**声音**（`references/05`）：原声主线；低切＋轻降噪＋温和压缩；配乐 −12 dB 基础＋sidechain；音效代码合成、只给真发生的事；−14 LUFS、混音峰值 −2 dBTP（编码后 ≤ −1）。

**验收**（`references/06`）：27 项量化＋接缝检查图＋独立评审；只有人能判断的（切点听感、待确认的字、示意画面会不会误导、配乐情绪、肤色、合规、真机上平台叠字）列进交付清单。

**踩坑**（`references/07`，一百多条）：最值钱的——字体编进代码包否则长片渲染挂；按帧号与采样号剪才不漂；字幕量「可读帧」不量动画起点；G 卡盖整句会冻住；升起转场切点帧不能露纸；素材库被挪走用 `--relink`。

| 情况 | 影响 | 怎么办 |
|---|---|---|

## 十、红线（任何 AI 都不能越过）

1. 密钥只读环境变量，不写进任何文件、日志、提示词卡。
2. AI 生成真调用前，必须把条数、总秒数、按平台当日价格估的费用报给用户，用户同意才加 `--yes`。
3. 不用陌生人的正脸（真人图库或 AI 生成）冒充出镜人、她的家人或客户。
4. 屏上非口播文字都要在 `facts.json` 有出处；转述不拼接、不改意、不加绝对化说法；不确定的进 `pending` 问人。
5. 出镜人姓名、身份、学制、数字口径以本人确认为准；没确认就在交付清单里写明，不能当已确认。
6. 不重画品牌 logo；AI 画面里的品牌字、假中文不用。
7. 理财类内容不写收益承诺；发布前过合规。
8. 工程不放桌面根目录；不删用户原片；不覆盖用户已校对的 transcript（ingest 会自动另存）。

## 十一、已知限制（2026-10-22 记，11-10 复核）

- 字幕断行靠「whisper 词号＋常用词表＋气口打分」，没有中文分词库；罕见专有名词可能断得不理想，看 `out/分镜表.md` 与成片抽帧复核。
- whisper small 对粤语、中英夹杂的识别一般；专有名词靠 `--prompt` 和人工校对。
- 「承接」转场（上一镜元素长成下一镜）、按动作类型分配缓动、快速运动的运动模糊还没做（`references/09`）。
- B 雾金玻璃、C 港刊大字两套风格包只做到风格帧与 11 秒小样级别验证，整片评审只在 A 上做过三轮。
- Windows 真机整条流程还没验证过（11-10 只验证了下载源、压缩包结构、脚本逻辑）。
- 非 macOS 没有画面文字识别；人脸偏航角用 OpenCV 关键点估算，比 Vision 粗。
