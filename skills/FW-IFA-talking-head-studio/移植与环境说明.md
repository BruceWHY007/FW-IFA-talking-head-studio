## 一、这个 skill 交付什么

**输入**：一条真人对镜头口播原片（手机或相机拍，竖版或横版都行）＋少量信息（出镜人姓名身份、系列名、有没有素材）。
**输出**：一支不用再剪、不用再包装、不用再找素材的竖版成片（1080×1920、30fps、−14 LUFS），以及一整套可追溯的工程文件。

整条线做的事：转写校对 → 逐句拆 A-roll（哪句留脸、哪句盖 B-roll、盖什么信息）→ 剪口癖、删重说、压停顿 →
B-roll 三路来源（用户素材库挑／免费素材库找／AI 生成接口，生成默认关闭）→ 风格包包装（刊头、字幕、名字条、标注、分屏、大字卡、下期预告）＋跟着说话走的动态 →
配乐自动避让与响度 → 25 项量化验收＋接缝检查 → 派独立评审子代理审片，改到「可以发布」。

结构基准是一支参考成片（复星财富 IFA 财经口播《全球抢钱大逃杀（上）》，拆解在 `references/01`）；设计借 IFA App 展示片的「视觉带与文字带分开」。

## 二、质量标准（用户给的 brief，原则全部保留）

用户在建 skill 时给了一份「动效导演」级的总要求，这是本 skill 的**底线，不是上限**。下表把每一条映射到 skill 里的落点，接手时任何一条都不能丢。

| 要求（原文要点） | 在本 skill 里怎么落实 | 在哪 |
|---|---|---|
| **角色**：动效导演兼创意技术人；设计、动画、配乐、质检全部用代码完成；拿同类最好的作品比，能摆在一起不露怯才算做完 | 全流程脚本化（Python＋Remotion）；每支片子对标参考片；独立评审子代理做「导演审片」 | `SKILL.md`、`references/06` |
| **brief 字段**（类型、主题、观众、结尾、时长画幅、帧率、品牌、事实来源、素材、风格、声音、自主度、工具链、落版），留空的由制作方决定并写理由 | 口播版 brief 模板，类型固定为「真人口播成片」 | `template/brief.md` |
| **explainer 模式**：只讲一个因果；画面文字不重复旁白 | 口播片的对应：A/B 判定；大字卡上与大字相同的字幕自动删 | `references/02`、`build.py` |
| **素材**：真 logo 用源文件不重画；截图不当静止板子；生成图只当参考；参考作品只学原则不照搬 | AI 画出来的 logo、假中文一律不用；照片卡用真图并写图源；参考片只拆结构与规律 | `references/02 §四`、`03 §四` |
| **craft 1**：第一帧是完成画面，钩子在第一秒 | 封面帧（画面窗里两行宋体大标题，停 1.2s），刊头用原话里的硬事实 | `packs/editorial.tsx` Cover |
| **craft 2**：一个物体贯穿全片 | 一条 2px 金线：刊头、接缝、名字条、标注签、关键词下划线、大字卡都从它开始 | `references/04 §一` |
| **craft 3**：转场由内容完成，硬切只切在节拍上 | 剪辑点＝开口帧；章节第一镜从接缝「升起」；分屏在说到第二件事时打开 | `build.py`、`Film.tsx` |
| **craft 4–5**：主运动＋错开的次级运动；速度变化、不用线性缓动 | 统一缓动表（进场快起慢收、离场慢起快走、推拉 S 曲线）；名字条、标注逐行错开揭开 | `theme.ts`、各 pack |
| **craft 6**：每个动作有看得见的结果 | 关键词变金＋下划线、方格涨光后字落格、指引线落到实物上 | `references/04 §三` |
| **craft 7**：文字是动效不是字幕；每词约 0.3s、最少 0.7s；画面太花垫底板；画面说明白的就删字 | 字幕每张 ≥0.7s；分带版式字永远不压画面；画面已说的字幕自动删 | `qa.py`、`build.py` |
| **craft 8**：景别与版式要变化，版式不重复 | 五类镜头（人脸／B-roll／照片卡／大字卡／手机里的她）＋分屏；跳切换景别 | `references/02 §三` |
| **craft 9**：停留镜头也要呼吸，任何东西不冻住；快速运动加模糊 | 人脸 3% 呼吸；验收「任何静止段 ≤0.5s（只量画面窗）」 | `Film.tsx`、`qa.py` |
| **craft 10**：只在讲空间关系时用 3D | 本 skill 不用 3D | — |
| **craft 11**：每个效果都要有理由；不要装饰粒子、泛滥渐变、素材库故障效果 | 动态语汇表每一项写明「什么时候用」；评审专查「为动而动」 | `references/04 §三`、`06` |
| **audio**：先做声音；音乐压低；音效只给真发生的事；有对白压音乐；−14 LUFS、真峰值 ≤ −1 dBTP；另出纯音乐版 | 原声即主线；配乐 sidechain 避让，判据「人声频带高出配乐，低 10% ≥12 dB」；音效代码合成、只 4–6 处；混音峰值 −2 dBTP 给编码留余量；出 `music_only.wav` | `mix.py`、`references/05` |
| **build**：所有内容是代码、同一条时间线、字体素材本地固定、逐帧渲染、密钥放环境变量、正式开工前渲 3–5 秒测试、数值是帧号的函数、无定时器无随机 | `timing.json` 单一真源；字体子集编进代码包；`render.py --test` 先渲 5 秒；密钥只读环境变量 | `build.py`、`render.py` |
| **workflow**：锁事实 → 研究参考 → 构思 2–3 个方向 → 分镜 ◆ → 风格手册与三张风格帧 ◆ → 声音 ◆ → 构建与评审循环 → 交付 ◆ | 对应 `SKILL.md §1` 十二步；风格方向三选一（`references/04 §四`）；◆ 处 gated 模式停下给人看 | `SKILL.md` |
| **critic loop**：做的人不评自己；每次整片渲染后派全新评审：抽帧、静音解读、同步检查、事实核查、导演审片；修最大的、重渲、再派新评审查全部；记 ledger | 评审提示词模板固定；每轮写 `qa/评审_第N轮.md`；`ledger.md` 记改前改后数字 | `references/06 §二` |
| **quality bar**：时长尺寸帧率准确；首帧完成；冻结限制；对比度 ≥4.5:1；安全区；同步 ≤1 帧；响度；静音能读懂；每条说法有出处；生成内容有标注 | `qa.py` 25 项＋`seams.py` 接缝图；facts.json 出处表；AI／示意角标 | `references/06 §一` |
| **deliverables**：成片、纯音乐版、10–20 帧缩略图、brief、facts、风格手册、timing、ledger、验收结果、待人确认清单 | 全部自动生成或模板化 | `SKILL.md §7` |

## 三、系统环境

### 3.1 已验证的环境（2026-10-22）

| 项 | 版本／配置 | 说明 |
|---|---|---|
| 机器 | Apple M3 Pro，18GB 内存 | 82 秒成片整片渲染约 105–110 秒（并发 3） |
| 系统 | macOS 26.5 | Linux 可用，见 §八 |
| ffmpeg／ffprobe | 8.1.1 | 必须有滤镜 loudnorm、sidechaincompress、acompressor、afftdn、alimiter、minterpolate、colorspace、ebur128、boxblur；编码器 h264_videotoolbox（没有就自动退回 libx264） |
| whisper.cpp | `whisper-cli`（Homebrew whisper-cpp） | 模型 `ggml-small.bin`（约 466MB），默认 `~/.cache/whisper-cpp/`，可用环境变量 `WHISPER_MODEL` 指定 |

| firecrawl CLI | 1.19.18 | 可选：Pexels 免费素材检索（Pexels 直连会被拦）；需 Firecrawl 账号与额度 |
| 字体 | 思源宋体 SC Heavy／SemiBold（OFL）、Bodoni Moda（OFL）随 skill 附带；苹方 PingFang SC 用系统字体 | 非 macOS 要换字幕字体，见 §八 |

### 3.2 网络

- npm 装包：**用 npmjs 官方源** `--registry=https://registry.npmjs.org/`（本机 npmmirror 连不上会卡死）。
- Pexels：通过 firecrawl 抓搜索页与视频页，视频文件直连下载。
- 生成接口（可选）：RunningHub `www.runninghub.cn`、火山方舟 `ark.cn-beijing.volces.com`、海螺 `api.minimax.cn`、可灵 `api-beijing.klingai.com`、fal `queue.fal.run`。

## 四、安装与自检

```bash
# 1. 放置（任选其一）
#    Claude Code：~/.claude/skills/IFA口播成片（可软链到正本 ~/.agents/skills/IFA口播成片）
#    Codex：     ~/.codex/skills/IFA口播成片
#    其他 AI：    放在任意目录，让它先读本文件和 SKILL.md；脚本都用相对 skill 根目录的路径
# 2. 装运行时（只一次）
bash IFA口播成片/scripts/setup.sh          # npm 走 npmjs；尝试复用本机已有的无头浏览器；编译人脸检测
# 3. 自检（随时可跑，不改任何东西）
bash IFA口播成片/scripts/doctor.sh         # 最后一行必须是 [doctor] OK
# 4. 系统依赖（macOS）
brew install ffmpeg whisper-cpp node
python3 -m pip install numpy pillow fonttools
curl -L --max-time 600 -o ~/.cache/whisper-cpp/ggml-small.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
npm i -g firecrawl-cli && firecrawl login     # 可选：免费素材
```

**规矩**：工程目录里永远不跑 `npm install`（node_modules 是软链到 skill 的共享运行时）；Remotion 版本只在 `runtime/package.json` 改，升级后先 `render.py --test` 冒烟。

## 六、数据契约（接手的 AI 要写的文件）

| 文件 | 谁写 | 关键字段 | 详见 |
|---|---|---|---|
| `brief.md` | AI 填，问人补 | 主题、观众、结尾、系列标题、出镜人、口径真源、素材开关、风格包、配乐、自主度、落版 | `template/brief.md` |
| `transcript.json` | 脚本生成，AI 改 `text` | `sentences[].text`（校对后）、`raw_text`／`chars`（勿改）、`drop`（删整句）、`_corrected` | `references/02 §一` |

## 七、规范汇总（每条都是实测或评审栽出来的）

**判定**（`references/02`）：钩子／观点／转折／情绪／号召留脸；现象、事实、名词、数字盖 B-roll；第一人称经历用本人素材；真实人物机构用照片卡；题眼词与关键数字用大字卡（≤3 张，只盖那个词＋≤1 秒引子）；讲「录视频、出镜」用「手机里的她」。开场 3–4 秒是脸＋名字条；人脸连续 ≤8.5s；B-roll 单条 1.6–6.5s；人脸占比 35–60%。

**素材**（`references/03`）：看图挑不看文件名；信息对得上、不误导、竖版能用、有动作、够长；**不用陌生人正脸冒充当事人或家人**；**AI 素材里有可读假中文或画出来的 logo 不用**；原片里有真东西就别先放示意的假东西；24/25fps 逐帧铺进 30fps；截取段不跨素材内部剪辑点；AI／示意画面挂角标。

**设计**（`references/04`）：三套风格包，默认 A 分带刊物（字永远不压画面）；宋体只给标题与大字、字幕苹方、数字 Didot、小标签细体大字距；纸上金色文字用铜金 `#7F5631`；带字的层零 transform；零描边零投影；数字不 count-up；任何静止段 ≤0.5s；剪辑点＝开口帧；动态都要说得出在交代什么。

**声音**（`references/05`）：原声主线；低切＋轻降噪＋温和压缩；配乐 −12 dB 基础＋sidechain；音效代码合成、只给真发生的事；−14 LUFS、混音峰值 −2 dBTP（编码后 ≤ −1）。

**验收**（`references/06`）：25 项量化＋接缝检查图＋独立评审；只有人能判断的（切点听感、待确认的字、示意画面会不会误导、配乐情绪、肤色、合规、真机上平台叠字）列进交付清单。

**踩坑**（`references/07`，41 条）：最值钱的——字体编进代码包否则长片渲染挂；按帧号与采样号剪才不漂；字幕量「可读帧」不量动画起点；G 卡盖整句会冻住；升起转场切点帧不能露纸；素材库被挪走用 `--relink`。

## 十、红线（任何 AI 都不能越过）

1. 密钥只读环境变量，不写进任何文件、日志、提示词卡。
2. AI 生成真调用前，必须把条数、总秒数、按平台当日价格估的费用报给用户，用户同意才加 `--yes`。
3. 不用陌生人的正脸（真人图库或 AI 生成）冒充出镜人、她的家人或客户。
4. 屏上非口播文字都要在 `facts.json` 有出处；转述不拼接、不改意、不加绝对化说法；不确定的进 `pending` 问人。
5. 出镜人姓名、身份、学制、数字口径以本人确认为准；没确认就在交付清单里写明，不能当已确认。
6. 不重画品牌 logo；AI 画面里的品牌字、假中文不用。
7. 理财类内容不写收益承诺；发布前过合规。
8. 工程不放桌面根目录；不删用户原片；不覆盖用户已校对的 transcript（ingest 会自动另存）。
