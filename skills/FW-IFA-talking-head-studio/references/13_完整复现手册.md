# 13 · 完整复现手册（给任何 AI Agent）

> 读者：第一次接手这个 skill 的 Agent（Claude、Codex、DeepSeek、WorkBuddy……）。
> 目标：只靠本文件＋仓库代码，把「一条真人口播原片 → 带 F 满幅讲述包装的竖版成片」完整做出来，效果和我们的验证片一致。
> 本质：**画面是代码渲出来的**（Python 脚本算时间线 → Remotion/React 渲帧 → ffmpeg 合成）。Agent 的工作是三件事：
> ① 校对与判定（写 JSON），② 跑脚本，③ 看图验收、按规则改。不需要也不允许「手动剪辑」。
> 版本：2026-10-29。环境安装见根目录 `移植与环境说明.md`；F 包几何与排版细则见 `references/11`；极简档见 `references/12`。

---

## 0. 三句话说清楚

1. **输入**：一条对镜头讲话的原片（手机竖拍或横拍都行），可选：系列名、本期标题、账号名、配乐。
2. **输出**：`out/成片_9x16.mp4`（1080×1920／30fps／−14 LUFS），外加分镜表、验收报告、抽帧图。
3. **两档**：**完整版**（默认，效果最全）和**极简档**（同一套视觉，判定和找素材自动化，省时间和 token）。开工前问用户选哪档、哪套风格（文字菜单，见 §3.0）。

## 1. 系统怎么分层（先建立心智模型）

```
原片.mp4
  │ ingest.py        ── 转写（whisper-cli，逐字毫秒时间）、抽音频、能量包络
  ▼
transcript.json      ── Agent 校对 text（错字、术语、数字口径）← 人
  │ numcheck.py      ── 带数字的句子重听原声，对不上标出来 ← 人听
  │ analyze.py       ── 逐句量：语速、口癖、重说、人脸正不正、清晰度 → A·宜留／A·可遮／需遮／删
  │ trim.py          ── 按 edits.json 剪口癖、压停顿 → aroll_cut.mp4＋voice_cut.wav＋transcript_cut.json（剪后时间轴）
  ▼
decompose.json       ── Agent 判定：每一镜是什么（人脸/B-roll/数字卡/信息卡…），盖哪句话（原话锚点），配什么 ← 导演逻辑在这
  │ stock.py         ── 免费素材检索／下载（完整版人挑；极简档 auto→review→redo）
  │ build.py         ── 把 decompose 翻译成逐帧时间线 timeline.json：锚点→帧号、字幕切卡、素材归一化、托底亮度…
  ▼
remotion/src/timeline.json
  │ render.py        ── Remotion 逐帧渲画面（分段 600 帧/进程）＋合成人声与配乐
  ▼
out/成片_9x16.mp4
  │ qa.py            ── 27＋项量化验收；qa_edge 近空画面；人看抽帧
```

**关键原则**：
- **一切时间用「原话锚点」，不用秒数**。原片一剪，秒数全变；锚点（"原话起…原话止"）由 build.py 在剪后逐字表里重新找，自动落到「开口帧」。
- **画面＝风格包（pack）×时间线数据**。同一份 timeline.json 换 `style` 就是另一种包装；包是 `template/remotion/src/packs/*.tsx`。
- **工程里的 remotion/src 是模板的副本**。改了 skill 模板里的 tsx，必须拷进工程：
  `cp ~/.agents/skills/IFA口播成片/template/remotion/src/packs/*.tsx <工程>/remotion/src/packs/ && cp …/src/Film.tsx <工程>/remotion/src/`。
  （10-29 栽过：改了模板没拷，验片看到的还是旧样式。）

### 2.1 transcript.json（Agent 只改 `text`）
```jsonc
{"sentences": [
  {"id": "s20", "start": 61.3, "end": 64.72,
   "raw_text": "再按中方投资额1-1.5%罚款",        // whisper 原样，别动（对齐用）
   "text": "再按中方投资额千分之一到千分之一点五罚款", // ★校对后的话；字幕、锚点都用它
   "chars": [{"c":"再","s":61.3,"e":61.4,"w":3}, …], // 逐字时间，别动
   "num_verified": true,                         // ★人听过原声确认数字无误（numcheck 不再报）
   "num_note": "用户听原声确认：千分之一到千分之一点五",
   "drop": false}                                // true＝整句删（重说的废稿）
], "_corrected": true}
```
`text` 和 `raw_text` 长度可以不同，`kb.sentence_chars()` 会把新文字对齐回逐字时间。

### 2.2 edits.json
`max_pause`（超过就压，默认 0.40s）、`keep_pause`（压到 0.20s，留气口）、`head`/`tail`、`cut: ["s03:那么"]`（剪口癖）、`keep`（显式保留）。

### 2.3 decompose.json（导演判定的全部落点）
顶层：`style`（F／A／B／C／K1／K2／K3；不写＝F）、`account`、`theme`、`title{series, episode, lines[两行刊头]}`、`disclaimer`、`outro`（落版秒数）、
`captions{highlight[说到就变金的词], gold[整行换金的句], silver[整行换银的句]}`、`texts[屏上字]`、`tracker[进度坞]`、`inserts[插条]`、`shots[镜头]`、`lite`（极简档标记）。

镜头 `shots[]` 通用字段：`id`、`type`、`cover`（原话锚点：`"起几个字…止几个字"` 或一段原话）、`why`（一句理由）。
| type | 是什么 | 专有字段 |
|---|---|---|
| B | B-roll（盖在她声音上的画面） | `pick`（`stock:名`/`lib:L008`/`gen:B07`/`file:路径`）、`in`（素材入点秒）、`layout`（F 包：full/pip/ring/glow/glowband/bands3/band/doc）、`picks`+`ins`（分带的第 2、3 条）、`move`、`focus_y`、`grade_extra`、`text_ok`、`q`（检索词） |
| G | 数字卡／词卡 | `figure{kind: number/word, value, unit, label, en, at}` |
| I | 信息卡 | `info{kind: compare/list/quote/timeline/chart, title, items[], source, surface:"paper"(皱纸单), numbered}` |
| P | 照片卡 | `image`、`credit` |
| PH | 手机里的她 | — |

`texts[]`：`{kind: step|stack|scatter, lines:[{t, at, tone, xy}], align, tone, top, num, until}`。
`inserts[]`：`{pos: top|bottom|corner, cover, pick, in, focus_y}`（盖在人脸段上，她还在）。
`tracker`：`{title, en, from, until, items:[{t, at}]}`（底部进度坞，讲「四个变化」时逐个点亮）。

### 2.4 facts.json（屏上每个字的出处）
`claims[{text, kind, source}]`（刊头、数字卡、词卡小标逐条）、`design_labels`（示意画面等设计用字）、`cards{I01:{kind, source}}`（信息卡一张一条）、`pending[]`（待用户确认）。
**source 写到句号＋原话**（例：`s16「都要在实施前10个工作日通过线上系统报」`）。数字类 source **不能只引转写**，要注明「原声核对」（见 §6）。
从别的工程拷来的 facts.json 一律按当前 decompose 重写（10-29：卡号、类型全对不上）。

### 2.5 timeline.json（build.py 输出，渲染唯一输入；Agent 不手改）
`fps、durationInFrames、style、theme、aroll{src, face{cx,cy,w}}、shots[{id,type,from,to,clip,clips,img,layout,figure,info,capScrim,text_ok…}]、arollZoom[{from,to,scale}]、captions[{from,to,lines[{text,from,hl,hlAt,tone}],hidden,hook,variant}]、masthead、texts、inserts、tracker、disclaimer、outro、sfx`。
- `capScrim`：该 B-roll 字幕带托底深度（build 量素材亮度算出，0.20–0.60）。
- `hidden`：这张字幕卡画面里不画（皱纸单／堆叠清单／步骤标题接住时），qa 也不量。

### 2.6 其他
- `broll/stock/stock_picks.json`：每条下载素材的 `source、id、url、w、h、fps、page、licence、credit`（出处与署名）。
- `broll/stock/auto_review.json`：自动素材审片 `{shots:{B01:{cover, sentence, pick, q_used, auto_flags[], verdict: keep|replace|drop, reason, rejected[]}}}`。
- `work/numcheck.json`：数字核对 `{rows:[{id, text, heard, text_nums, heard_nums, flag, warn, verified}], unresolved}`。

## 3. 流水线逐步（完整版）

每步：**命令 → 产物 → Agent 要判什么**。◆＝必须停下来等用户（gated 模式）。

### 3.0 ◆ 开工前：给用户一个文字菜单（不渲样片）
只发编号、名称、一句话，预览图在 `references/assets/styles/`（剪影样片，无人脸）：
```
1 F 满幅讲述（默认）——她满幅在说，小窗/分带/B-roll 轮换，数据上玻璃卡，重话金银字
2 A 分带刊物　3 B 雾金玻璃　4 C 港刊大字　5 K1 证据桌　6 K2 图解　7 K3 IFA 品牌刊
再选一档：完整版（默认）／极简档（省时省 token，同一套质感）
```
用户不回或回「默认」＝ F＋完整版。只有用户要「用我自己的脸看样子」才跑 `catalog.py --video 原片`（2–4 分钟）。

### 3.1 建工程、转写
```bash
python3 scripts/new_project.py <工程目录> <原片.mp4>
python3 scripts/ingest.py <工程目录> [--prompt "术语：BVI、SPV、QDII、跨境理财通"]
```
产物：`transcript.json`、`work/aroll.mp4`、`work/voice.wav`、`work/sheet_2s.jpg`。

### 3.2 校对转写 ★
逐句改 `text`：错字、人名、机构名、术语、**数字口径**。改完顶层加 `"_corrected": true`。
数字口径规则：口播说「千分之一」就写「千分之一」，**不要**写成 1%；说「十个工作日」写「10个工作日」可以（数值和单位不变）。

### 3.3 ◆ 数字核对原声 ★（10-29 新增，不许跳）
```bash
python3 scripts/numcheck.py <工程目录>
```
- ❌「单位」：转写写 %，原声是千分之／万分之（或反之）→ 必改。
- ❌「数值」：两边数值不一样 → 让用户听（重听也会吞「点」：「一点五」听成「五」）。
- ⚠️「重听没听到数字」→ 屏上用到这句的数字请人听。
处理：改 `text` → 加 `num_verified: true` 和 `num_note` → 重跑 numcheck → 再往下。

### 3.4 拆 A-roll、粗剪
```bash
python3 scripts/analyze.py <工程目录>     # 看 work/aroll_sheet.jpg（逐句一格，带标签）
# 写 edits.json（剪哪些口癖、停顿压多少）
python3 scripts/trim.py <工程目录>        # 剪后 aroll_cut.mp4／voice_cut.wav 同长（差 0ms）
```
改了 transcript.json 的 text 之后**必须重跑 trim.py**（剪后逐字表 transcript_cut.json 由它生成）。

### 3.5 ◆ 判定：写 decompose.json（导演逻辑，见 §4）
```bash
python3 scripts/suggest_style.py <工程目录>    # 按逐字稿给风格推荐与封面形式建议（参考）
```

### 3.6 找素材
完整版：每个 B 镜头写 `q`（英文画面词）或靠概念词表，人看候选图挑：
```bash
python3 scripts/stock.py <工程> plan --decompose decompose.json   # 每镜一张候选图（带角标：字/脸/暗/静）
python3 scripts/stock.py <工程> get pexels:35176127 st_hk_central_boc
```
政策原文用官方网页截图：`node scripts/webshot.mjs <url> "要高亮的原句" <输出.png> --clean`（layout: doc）。
用户自己的素材：`broll_index.py` 建库，`pick: lib:L008`。AI 生成：默认关闭，只出提示词卡（`gen_providers.json`）。

### 3.7 build → 看报警 → 改 → 再 build
```bash
python3 scripts/build.py <工程> --decompose <工程>/decompose.json      # 首次（含素材归一化）
python3 scripts/build.py <工程> --no-conform --decompose …              # 只改了判定、没换素材时（快）
```
build 的报警逐条处理（常见：锚点找不到、人脸 12 秒无版面事件、卡片超 25%、数字没核对、自动素材没审完、信息卡没登记出处）。

### 3.8 关键帧验收（不渲整片）
```bash
python3 scripts/render.py <工程> --stills 120,500,1900,5200    # 帧号看 out/分镜表.md
```
每类至少看一张：人脸＋字幕、每种 B-roll 版式、数字卡、每种信息卡、皱纸单、原文截图、结尾。

### 3.9 整片（用户要时才渲）＋验收
```bash
python3 scripts/render.py <工程> [--out 成片_F_v2.mp4]     # 分段渲染，约 4–7 分钟／3 分钟片
python3 scripts/qa.py <工程> [--video out/成片_F_v2.mp4]
```

## 4. 导演逻辑（decompose 怎么判）

### 4.1 哪句留脸、哪句盖 B-roll
| 句子类型 | 处理 | 为什么 |
|---|---|---|
| 钩子、观点、转折、号召、情绪 | **留脸**（A） | 观众信的是人；这些句子要看她的表情和手势 |
| 事实、名词、地点、数字、流程 | **盖**（B／G／I） | 信息靠画面承载，看脸反而记不住 |
| analyze 标「需遮」（侧脸、低头看稿、卡壳） | 必须盖或删 | — |
| 重说的废稿 | `drop: true` | — |

### 4.2 F 包「节拍 → 画面处理」对照
| 她在说 | 用 | 例 |
|---|---|---|
| 开场钩子 | 满幅人脸＋84px 钩子字幕 | 「12月1日，一份文件将要生效」 |
| 引出主体／对象 | `bands3` 三条分带（同题材三段） | 「它管的不是企业，是你我这样的个人」 |
| 引用政策原文 | `doc` 官方截图＋荧光扫句 | 「发改委公布了…第49号令」 |
| 一个词就是题眼 | G 词卡（暗底金尘、金属大字＋英文副行） | 「名字里去掉『企业』两个字」 |
| 一个硬数字 | G 数字卡（只盖那个词＋≤1 秒引子） | 「10个工作日」 |
| 两件事对比 | I `compare` 玻璃卡 | 发改备案 vs 外汇购付汇 |
| 「第一、第二…」 | `texts.step` 步骤标题＋`tracker` 进度坞 | 四个变化 |
| 列举 3 项以内 | `texts.stack` 堆叠清单（≤3 行，可 `num:true`） | QDII／港股通／跨境理财通 |
| 明确说「四条／三类」的清单 | I `list`（玻璃）或 `surface:"paper"` 皱纸单（带 1234） | 出海前自问四条 |
| 原话金句 | I `quote` | 「备案只是外汇的必要条件，不是充分条件」 |
| 叙述性内容、她继续讲 | `pip`/`ring`/`glow`：B-roll 满幅，她在小窗里继续说 | 二级市场照旧 |
| 场景过渡 | `full` 满幅 B-roll | — |
| 最硬的判断 | `captions.gold/silver` 整行金银、`emphasis` 快推 | 「现在是要真掏钱」 |

### 4.3 密度与节奏（硬线，build/qa 都查）
- 人脸占比 45–75%；信息卡＋大字卡合计 ≤25%；满幅人脸连续 12 秒内必须有一次版面事件（插条、屏上字、金银整行、进度坞点亮、景别变化）。
- B-roll 单条 1.6–9 秒；同一种小窗版式不连用三次；相邻两条 B-roll 主体不同类（人／手／建筑／文件／物件／空镜）。
- G 卡只盖那个词＋前面 ≤1 秒引子；字落下后至少完整可读 1.3 秒。
- 一支片子 I 卡 1–3 张、和 G 卡合计 ≤5 张——多了就成了 PPT。
- 判据：把字幕全遮掉，只看卡，能说出这条片子的三件事。

### 4.4 B-roll 选材准则
1. **贴题**：画面主体和这句话说的东西有直接关系；抽象概念先查 `template/broll_lexicon.json` 换成拍得到的东西（财富→点钞，控制→棋盘，禁止→锁）。
2. **地域真**：讲中国内地／香港的事，画面里不能有外国国旗、外国政府建筑、外文招牌；检索词别用 flag／government／parliament，地点要真就加 `hong kong`／`china`。
3. **不冒充**：不用陌生人正脸冒充当事人或家人；AI 素材里的假中文、假 logo 不用；原片里有真东西就别先放示意的假东西。
4. **画面干净**：不暗（字幕带亮度不低于人脸镜一半）、不抖、无水印；画面里有可读文字要和事实一致，否则换（本意就要露的写 `text_ok: true`）。
5. **前后接得上**：和前后画面亮度、冷暖不突兀；同一条素材全片只用一次。

### 4.5 字幕与屏上字口径
- 字幕＝口播原话（校对后），不改写；关键词说到那一帧才变金。
- 屏上转述不拼接、不加绝对化说法；数字照原声（§6）。
- 同一处只出一种字：皱纸单、堆叠清单、散点关键词在屏时字幕让位；「第一」字幕被步骤标题大字接住时不出。

## 5. 包装设计逻辑（F 满幅讲述）

### 5.1 结构：四层恒定＋一层轮换
| 层 | 规格 | 设计意图 |
|---|---|---|
| ① 刊头 | 两行宋体 62px／行距 76，顶 y=100，白字柔影；只在看得见她的帧出现 | 像杂志栏目头，告诉观众「这是什么系列、这期讲什么」 |
| ② 字幕 | 宋体 Heavy 66px，一行，中心 y=1118；卡片／原文截图在屏时落到 y=1380 | 一行大字，竖屏一眼读完；不加底板 |
| ③ 底部声明 | y=1800，33px，72% 白＋双层影；白纸上换深墨色 | 合规常驻，不抢戏 |
| ④ 真实性角标 | 声明上方右侧 21px「示意画面／AI 生成」 | 合规 |
| ⑤ 画面处理（轮换） | 满幅人脸／插条／B-roll 满幅／小窗（方窗、光晕圆、细环圆）／三条分带／横版画框条／原文截图／玻璃卡／皱纸单／标题卡 | 节奏靠「处理方式换」而不靠「剪碎」 |

### 5.2 字体分工
宋体（思源宋体 Heavy／SemiBold）＝标题、字幕、大字；苹方＝卡片正文、小标签；Didot（Bodoni Moda）＝数字。
字体在 build 时按本片用字切子集、编进代码包（`fontdata.ts`）——**不能用 URL 加载**，长片渲染会超时挂掉。

### 5.3 颜色（暖金体系）
- 金属金渐变：`#FFF9DE → #FCE7A6 → #F5CB64 → #E6AE3F → #FAE08E`（暗位不低于 #E0A63A，否则亮底上读成黑铜）。
- 纸面深金：`#EBBB5A → #D29A30 → #B27414 → #9A6010 → #D49A2E`（浅底上要压深两档，对纸 ≥4.5:1）。
- 银：`#FFFFFF → #F1F2F4 → #A7ACB4 → #E6E8EB → #FFFFFF`。
- 玻璃卡：字 #FFF8EA、次级字 90% 白、强调 #F4CF86、卡底 84–90% 深暖黑。

### 5.4 可读性机制（为什么字在任何底上都看得清）
1. 字幕白字：柔影 `0 2px 4px .85 / 0 4px 18px .55`＋两圈暗晕（14px .45、40px .55）。
2. 金银字：`drop-shadow`（不是 text-shadow——金属字是透明的）＋深棕 1.2px 细边＋5px/18px 暗晕。
3. **金属字的祖先元素不能有 text-shadow**：影子会画在渐变上面，把金压成黑铜。
4. 字幕带托底：默认 0.20；亮底 B-roll 由 build 量字幕那一带亮度给 `capScrim`（0.20–0.60）；卡片／原文截图在屏时托底跟着字幕落低位；**皱纸单不画任何托底**（白纸上灰带很脏）。
5. 底部托底 320px 渐深到 0.55，托住声明。

### 5.5 动效规则
- 文字层零位移：只用遮罩（clip-path）揭开、不透明度降档；数字不做 count-up。
- 卡片在切点前 2–4 帧开始落、切点那一帧已基本到位（不露空卡、不闪白）。
- 标题卡背景要「活」：垫她的虚化原片（同步、压暗）＋金色光斑缓慢漂移＋光束旋转；文字不动。
- 小窗里的她慢推 4%；人脸段景别 1.00／1.06 交替做跳切；最硬 1–3 句 15 帧快推到 1.10–1.14。
- B-roll 运镜按画面选：push／pull／pan-l／pan-r／hold。

### 5.6 排版细则（违反就会被打回）
单位 ≤2 字跟数字同基线（`%`、`‰`、`年`）；区间横画成居中细线；说「几条」的清单必须有序号（序号列左对齐、整块居中）；多字术语不拆行、引号不和字分家、不断在「的」前；卡上最小字号：标签 30、备注 26、来源 22。

## 6. 数字与事实（错一个数字＝事实错误）

1. **转写会改数字**：whisper 把「千分之一到千分之一点五」写成「1-1.5%」（错 10 倍）；换提示又会把「一点五」吞成「五」。
2. 所以：校对时数字照原话写 → `numcheck.py` 重听对比 → 对不上的让人听 → `num_verified`。
3. 屏上数字（数字卡、信息卡、刊头）只能来自核对过的句子；`facts.json` 的 source 注明「原声核对」。
4. 有 HR／业务给的定稿海报或文字稿时，数字按定稿原文，不自己换算、不说「或」。
5. 政策解读类发布前过合规；转述（不是原话）的地方进 `facts.pending`。

## 7. 极简档的素材审片（auto → review → redo）

```bash
python3 scripts/lite_plan.py <工程> --series 跨境合规笔记 --episode 个人出海之前，先看清这四条
python3 scripts/stock.py <工程> auto --decompose decompose_lite.json      # 自动取＋出审片表

```
审片表每行：**[前一个画面][素材三帧][后一个画面]**＋原话、检索词、自动提醒（亮度差 >55、冷暖差 >45、和上一条同检索词、和某条画面几乎一样）。

## 8. 代码实现要点（改代码前必读）

### 8.1 build.py（scripts/build.py，按节）
0. 账号主题与形式登记（`_口播形式登记.json`：同账号沿用主题、错开封面形式）；数字核对与自动素材审片的报警。
1. 全片逐字表（剪后），ASR 0 长度字报警。
2. 镜头→时间：锚点在剪后文字里找（标点不参与），入点落到**开口帧**（跳过标点）；太短的镜头往前长；G 卡锚点 >1.2s 报警。
3. 跳切处换景别（1.00／1.06 交替），短于 12 帧的景别碎段合并。
4. 素材归一化：统一调色、按版式实际框裁（`F_MAIN`：bands3 每条 1080×650、glowband 主素材 1080×1200、下条 1080×720）、**先设时间基 `settb=1/30,setpts=N`** 再逐帧铺进 30fps（否则 24/25fps 素材每 6 帧重复 1 帧）；内部剪辑点检测（不跨镜头取段）。
5. 刊头、名字条、封面、落版。
6. 字幕：按标点切短语、F 包一行 ≤12 字、关键词开口帧变金；**最短 0.7s：先把短卡往前提 ≤5 帧（前一张仍 ≥0.7s、起点无剪辑点），不够再把下一张往后推最多 1 帧**；同卡第二行比第一行晚 ≤8 帧就一起出；F 包标 `hidden`。
7. 音效事件（只给画面里真发生的事）。
8. 写时间线（含 `capScrim`：量 B-roll 在字幕带的平均亮度，Y≤80→0.20，线性加深，封顶 0.60）。
9. 字体子集编进代码包、质感贴图。
10. 分镜表与占比；F 包节奏检查（12 秒事件、人脸 45–75%、卡 ≤25%、小窗不连用三次）。

### 8.2 渲染层（template/remotion/src）
- `Film.tsx` 层序（下→上）：Under → 画面窗（A-roll → B-roll Sequence → G 卡 → P 照片 → I 信息卡）→ 小窗（Pip）→ Over（托底＋声明）→ 刊头 → Layers（插条、进度坞、屏上字）→ 角标 → 标注 → 名字条 → 落版 → 字幕 → 封面 → 颗粒（overlay 6%）。
- `packs/fullbleed.tsx`：`FB` 几何常量、`Scrim`（托底，按镜头类型与 capScrim）、`Masthead`、`Caption/LineText`（字幕，CAP_SHADOW、CAP_METAL_FX）、`Foot`（声明）、`BRoll`（8 种版式）、`Speaker/Pip`（小窗里的她，按人脸中心取景、慢推）、`Inserts`、`Texts`（step/stack/scatter）、`Tracker`、`TitleBg/Figure`（标题卡）、`GLASS`（玻璃卡材质）、`PaperList`（皱纸单）。
- `packs/info.tsx`：五种信息卡的通用排法（材质由包给），`unitInline`、`NumText`（区间细线）。
- `render.py`：分段渲染（600 帧／进程、无损拼接、核帧数），`--stills` 渲关键帧，`--frames` 渲片段；compositor 报错自动降并发。

### 8.3 qa.py 口径（F 包与其他包分开）
冻结（相邻帧 <0.35 **且** 隔 6 帧 <0.5 才算静止；皱纸单量方窗里的她）、画面窗空白帧、响度 −14±1／真峰值 ≤−1、字幕对位（按这行首字的开口帧，可读帧早 ≤6 晚 ≤1）、字幕停留 ≥0.7s（hidden 不量）、对比度（F 包按每行真实字号、量字形外 6–13px、≥3:1 大字线）、安全区 x≤940、屏上文字有出处、数字已核对原声、大字卡可读 ≥1.3s、人脸碎片、B-roll 重复帧／亮度下限／曝光跳（同向像素 ≥70%）／可读文字（OCR）、片尾杂音、F 包节奏（12 秒事件、B-roll 1.6–9s、人脸 45–75%）、近空画面。
**qa 只是体检**：底部声明对比度、素材贴不贴题、画面好不好看，要人看帧。

## 9. 最容易栽的 15 个坑（全文见 references/07）
1. 改了 skill 模板没拷进工程 → 渲出来还是旧样式。
2. 字体用 URL 加载 → 长片中途超时挂掉；必须编进代码包。
3. 整片一个进程渲 → ~1280 帧处断；用分段渲染。
4. 按秒数定镜头 → 一剪全乱；用原话锚点。
5. 24/25fps 素材不先设时间基 → 每 6 帧重复 1 帧。
6. 转写把千分之写成 % → 先 numcheck。
7. 金属字祖先有 text-shadow → 金字发黑。
8. 字幕托底在白纸上照画 → 灰带压字；皱纸单不画托底。
9. 字幕压在分带接缝上 → glowband 接缝 1200。
10. 自动素材不审 → 外国国旗、外国政府楼。
11. 检索词用 flag／government → 必出外国素材。
12. 文件已存在就不重下 → 文件和记录对不上；redo 先删再下。
13. facts.json 从别的工程拷来 → 卡号对不上。
14. 量了看不见的字幕／用别的包口径卡 F 包 → 假红灯；先判是不是量错，再改画面。
15. 为了让读数过线改画面 → 先看帧，读得清就记录原因，不为数字牺牲风格。
