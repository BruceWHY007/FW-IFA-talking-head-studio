# 生成接口备忘（核对日期写在每段开头；接口会变，接入前再对一遍官方文档）

配置文件：`template/gen_providers.json`；执行器：`scripts/gen_video.py`。本文件只记**核对过的字段**，未核对的在配置的 `verified` 里写明。

## 火山方舟 Seedance（2026-10-22，官方文档「创建视频生成任务」「查询视频生成任务」）

- 建任务：`POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`，头 `Authorization: Bearer $ARK_API_KEY`
- body：`model`（如 `doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-260128`、`doubao-seedance-2-5-260628`）、
  `content`（数组：`{"type":"text","text":…}`；图 `{"type":"image_url","image_url":{"url":…},"role":"first_frame|last_frame|reference_image"}`）、
  `ratio`（16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9 / adaptive）、`duration`（2.0 系列 4–15 或 -1）、`resolution`（2.0 fast 只有 480p/720p）、
  `generate_audio`、`watermark`、`seed`
- 首帧／首尾帧／全模态参考三种场景互斥；Seedance 2.5 在首帧／首尾帧任务里 ratio 只能 adaptive
- **2.0 / 2.5 系列不收含真人人脸的参考图**（要用平台的授权或虚拟人像流程）——出镜人的镜头只能用实拍
- 查任务：`GET …/tasks/{id}`；`status`：queued / running / cancelled / succeeded / failed / expired；成功后 `content.video_url`（**24 小时有效**）
- 开通条件：账户余额 >200 元、或 200 元以上节省计划、或资源包

## RunningHub（2026-10-22）

- **AI 应用通道**（本机《向光而行》项目实际跑通）：`POST https://www.runninghub.cn/task/openapi/ai-app/run`，body `{webappId, apiKey, nodeInfoList:[{nodeId, fieldName, fieldValue}]}`，头带 `Authorization: Bearer <key>` 与 `Host: www.runninghub.cn`。
  普通级 key 调不了标准模型接口（错误码 1014）时走这条。当时用过的应用：Seedance 2.0 Fast 全能生视频 `2065722002014564353`（节点 21：prompt / duration / ratio / resolution；节点 27：首帧图，先走 `/task/openapi/upload`）、Seedance2.0 全能视频 `2047318799191384065`。
- **工作流通道**（官方 apifox 文档）：`POST /task/openapi/create`，body `{apiKey, workflowId, nodeInfoList}`；工作流先在网页手动跑通；节点号在节点右上角，字段名从「导出 Workflow API」里看。
- 查状态：`POST /task/openapi/status` `{apiKey, taskId}` → `data`：QUEUED / RUNNING / SUCCESS / FAILED
- 取结果：`POST /task/openapi/outputs` `{apiKey, taskId}` → `data[0].fileUrl`
- 坑：偶发 SSL EOF／连接中断要重试；大文件下载不要走本地代理（会被掐）。免费账号不能用 API。

## MiniMax 海螺（2026-10-22，只核对了建任务）

- `POST https://api.minimax.cn/v1/video_generation`，`Authorization: Bearer`；`model`：MiniMax-Hailuo-2.3 / MiniMax-Hailuo-02 / T2V-01-Director / T2V-01；
  `duration` 6（768P 可 10）；`resolution` 720P / 768P / 1080P（1080P 只 6 秒）；`prompt_optimizer`；回 `task_id`
- 文生视频页面没有画幅参数 → 出 16:9，进片走画框条
- 查询与取文件两步（`/v1/query/video_generation`、`/v1/files/retrieve`）按惯例填写，接入时核对
