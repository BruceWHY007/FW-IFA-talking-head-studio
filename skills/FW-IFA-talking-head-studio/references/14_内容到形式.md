# 14 · 内容到形式（信息卡怎么跟着内容换）

> 2026-10-31 定。规则一句话：**风格按账号锁，变化来自内容。**
> 同一个号，刊头、字体、暖金、玻璃卡、讲解人小窗一律不动；观众觉得「这条不一样」，靠的是信息换了一种呈现方式。
> 这一页只讲六种新形式怎么用。风格层见 `04`，F 包规格见 `11`。

## 零 · 先记住三条

1. **一种形式，一支片子里只当一次主角。** 同一种形式出现第二次，观众就当它是模板了。一支片最多两种新形式（主角＋一次配角），其余用原来的 compare／list／timeline／chart／quote 和屏上字。
2. **形式由那句话的结构决定，不由你想不想换花样决定。** 内容是「几个同类数字比高低」就只有数轴对；内容是「以前怎样、现在怎样」就只有前后拉杆对。对不上就别用，用原来的卡片。
3. **风格层一行代码都不改。** 字体、配色、材质、版面几何全部来自当前风格包的 `InfoStyle`。六种形式在七套包里都验过，换包自动换皮。

## 一 · 决策表（先看这条内容属于哪一类）

| 她在说什么 | 形式 | kind | 动作 |
|---|---|---|---|
| 几个同类数字比高低（中位数 2 万 1／你的 3 万／金融业 3 万 4） | **数轴** | `scale` | 尺子先画出来，说到哪个数，哪个标记落下；「你」用强调色 |
| 占比、几成、排位（一年涨了两成） | **点阵** | `dots` | 一百个点先铺好，说到占比，那部分点像波纹一样亮起 |
| 以前怎样、现在怎样（以前警告，现在真掏钱） | **前后拉杆** | `beforeafter` | 说到「现在」，金色分割杆先快后慢扫过去，扫过的地方换成新内容 |
| 先后、因果、一层压一层（没收 → 罚款 → 禁投 → 联合惩戒） | **链条** | `flow` | 连线先描到，节点再落下，说到哪一层哪一层亮 |
| 几件事共同决定一个结果（四种能力 → 越稀缺） | **汇聚** | `converge` | 来源逐个出现各自连线，说到结论时线变金、光点流进结论卡 |
| 两地、跨境、资金怎么走（境内 → 境外主体 → 返程投回境内） | **航线** | `route` | 两地落针，飞线连过去，光点沿线走，返程用虚线另画一条 |

**不属于这六类的**：并列清单（用 `list`）、时间顺序（`timeline`）、两个数并排（`compare`）、一句金句（`quote`）、几个关键词（`texts.scatter`）。**不要为了用新形式把内容掰弯。**

## 二 · 每种怎么写（照抄字段名，写错 build 会停）

所有形式共用：`type: "I"`、`info.kind`、`info.title`（≤16 字）、`info.source`（来源行，**必填**，她自己的话就写「口述」）。
`at` 可以写**句号**（`"s15"`）或**原话片段**（`"境外主体"`，要能在句子里唯一匹配）；不写就按覆盖区间的起点依次排。

### 数轴 `scale`

```json
{"id": "I01", "type": "I", "cover": "s04–s08", "why": "三个数放一把尺，看出她落在哪",
 "info": {"kind": "scale", "title": "月薪 3 万，落在哪", "unit": "港元 · 月薪",
  "items": [
   {"label": "全港雇员中位数", "v": 21200, "show": "21,200", "at": "s04"},
   {"label": "月薪 3 万", "v": 30000, "show": "30,000", "me": true, "at": "s05"},
   {"label": "金融及保险业中位数", "v": 34000, "show": "34,000", "at": "s08"}],
  "source": "2025 年政府统计（口述）"}}
```

- `v` 是**用来定位置的数值**（数字，不带单位）；`show` 是屏上显示的字（可带千分位），不写就显示 `v`。
- `me: true` 只给**她自己在说的那个数**（金色）。一条最多一个。
- `label` ≤10 字；`show` ≤8 字。`unit` 写在轴右边，≤8 字。
- `min`／`max` 可选，不写自动留 22% 余量。两个数差距太小时宁可写 `compare`。

### 点阵 `dots`

```json
{"id": "I02", "type": "I", "cover": "s12–s13", "why": "两成用一百个点亮出来",
 "info": {"kind": "dots", "title": "香港管理的资产", "value": 0.2, "show": "两成",
  "label": "一年涨了两成，已经到 42 万亿港元",
  "items": [{"at": "一年涨两成"}], "source": "口述"}}
```

- `value` 是 0–1 的小数（两成＝0.2，四分之一＝0.25）。**不写百分号。**
- `show` ≤6 字（「两成」「21%」）；`label` ≤28 字，一句话说清这个占比意味着什么。
- `from: "bottom"` 可选，默认从左上往右下亮。
- 只用于**一个**占比。要对比两个占比，写两张 `dots` 或一张 `compare`。

### 前后拉杆 `beforeafter`

```json
{"id": "I03", "type": "I", "cover": "s23", "why": "以前和现在两句话正对着",
 "info": {"kind": "beforeafter", "title": "处罚变了",
  "items": [
   {"tag": "以前", "t": "警告加责令改正", "icon": "doc"},
   {"tag": "现在", "t": "要真掏钱", "icon": "coin", "at": "现在是要真掏钱"}],
  "source": "口述"}}
```

- `items` **正好两条**：`[以前, 现在]`。第二条的 `at` 就是**拉杆扫过去的时刻**——她说到「现在」才开始扫。
- `tag` ≤6 字（以前／现在、过去／今年、旧规／新规）；`t` ≤14 字；`d` ≤28 字可选。
- 左边那条自动降饱和；要用划掉（误区）加 `"strike": true`。
- 两句必须是真的前后对照。只是转折（「不是 A 而是 B」）用 `compare` 或金银整行，不用拉杆。

### 链条 `flow`

```json
{"id": "I02", "type": "I", "cover": "s19–s22", "why": "罚则一层压一层",
 "info": {"kind": "flow", "title": "罚款硬了，一层压一层",
  "items": [
   {"t": "没收违法所得", "icon": "wallet", "at": "s19"},
   {"t": "按投资额罚款", "d": "千分之一到千分之一点五", "icon": "coin", "at": "s20"},
   {"t": "1–3 年禁投", "d": "罚完之后禁止对外投资", "icon": "clock", "at": "s21"},
   {"t": "跨部门联合惩戒", "icon": "network", "at": "s22"}],
  "source": "口述"}}
```

- 3–5 个节点，**有先后或因果**才用。并列的几件事用 `list`。
- `t` ≤10 字，`d` ≤16 字。节点框高随数量自动缩，5 个以上会太挤。
- `"back": true` 加一个**回头**节点（罚完给整改机会、绕回原处）：它会从最后一个节点拉一条回线，`t` 写回线上那个标注。
- 节点要配图标时用 `icon`（见第四节）。

### 汇聚 `converge`

```json
{"id": "I03", "type": "I", "cover": "s26–s30", "why": "四种能力汇到「越稀缺」",
 "info": {"kind": "converge", "title": "被抢的是什么样的顾问",
  "items": [
   {"t": "多资产配置", "icon": "pie", "at": "s26"},
   {"t": "懂内地客户", "icon": "chat", "at": "s27"},
   {"t": "跨境税务信托", "icon": "globe", "at": "s28"},
   {"t": "合规不出错", "icon": "shield", "at": "s29"},
   {"result": true, "t": "越稀缺", "d": "能力叠得越多越稀缺", "at": "s30"}],
  "source": "口述"}}
```

- 3–4 个来源＋**一个** `result: true` 的结论。结论必须是她**说出来的**一句原话，不是你替她总结的。
- 来源 `t` ≤7 字（很短，只放名词）；结论 `t` ≤7 字、`d` ≤16 字。
- 说到结论那一刻，所有线变强调色、光点流进结论卡——所以结论的 `at` 要对准她说完那句的**落点**，不是开口。

### 航线 `route`

```json
{"id": "I01", "type": "I", "cover": "s15", "why": "资金路径：境内→境外主体→返程",
 "info": {"kind": "route", "title": "境外再投资，要事前报告",
  "items": [
   {"t": "境内", "d": "你本人", "at": "s15"},
   {"t": "境外主体", "d": "你控制的公司", "at": "境外主体"},
   {"via": true, "t": "再投资", "at": "再去投资"},
   {"back": true, "t": "返程投回境内", "at": "返程"}],
  "source": "口述"}}
```

- 2–3 个地点（普通条目）＋可选的 `via`（途经／中间那一步）＋可选的 `back`（回程）。
- 地点 `t` ≤6 字；`d` ≤12 字。
- `via` 是飞线上的小标签，`back` 用虚线另画一条**反方向**的弧——回程、回流、返程才用。
- **只有真的讲两地／跨境才用。** 讲「香港是国际金融中心」这种没有路径的话不要用。

## 三 · 元素：图标／勾／叉／问号

**图标**：任何条目都可以加 `"icon": "coin"`，取 `template/remotion/src/packs/icons.ts` 里 IFA图文卡 定稿的 40 个线框图标。
常用：`coin` 钱、`wallet` 钱包、`doc` 文件、`shield` 合规、`globe` 跨境、`bank` 银行、`clock` 时间、`chat` 沟通、`phone` 工具、`award` 牌照、`home` 房产、`pie` 配置。
图标只做**辅助识别**，不替代文字；一条卡最多每个节点一个，不要每项都塞。

**清单卡的三种标记**（原来的 `list` 才有，新形式里用图标就好）：

```json
{"kind": "list", "mark": "check", "title": "先做这三件", "items": [...]}   // 要做的事
{"kind": "list", "mark": "cross", "title": "三个误区",  "items": [...]}   // 文字上划一道
{"kind": "list", "mark": "q",     "title": "选平台前先问清", "items": [...]} // 问号，问题清单
```

`q` 适合「该问的问题」，`cross` 适合「别这么干」，`check` 适合「照着做」。**一张卡只用一种标记。**

## 四 · 全片纪律（build.py 会查）

| 规则 | build 怎么查 | 怎么改 |
|---|---|---|
| 一种形式全片只当一次主角 | 同一 `kind` 出现 ≥2 次 → ⚠ | 第二次换成 `list`／`compare`，或删掉（内容重复说明她本来就在重复） |
| 全片新形式 ≤2 种 | 不同 `kind` ≥3 种 → ⚠ | 留最贴内容的那两种 |
| 同账号连着两支形式要错开 | 读工程上一级的 `_口播形式登记.json`，上一支用过的主角形式再出现 → ⚠ 提示 | 换一种，或确认这一支内容确实只有这一种对 |
| 风格层不动 | 新形式不走自己的字体／配色 | 只在 `InfoStyle` 里取色取字 |

**账号登记**：`make.py` 每渲完一支，在工程上一级目录写 `_口播形式登记.json`（账号、风格包、主题、封面形式、卡型）。
所以「同一账号的工程放同一个上级目录」不是为了整齐，是为了让登记读得到。新形式不用另建登记，`cards` 里就有它的 `kind`。

## 五 · 验收（渲完看这几帧）

1. **开口帧**：每个条目落定的时间点，对回原声——她说这个词的那一帧才出现，早了像抢话，晚了她已经说过。
2. **文字零变形**：新形式里带字的层只做 `clip-path` 揭开和透明度，**不许整体缩放／模糊进出**（和 04 同一条纪律）。
3. **数字不 count-up**：数轴上的数字在它落定那一帧就是终值，不跳数。
4. **落定后有呼吸**：卡面静止没关系，讲解人小窗和底层原片还在动；qa 的冻结检查只量画面窗。
5. **压不住字幕**：信息卡区域下沿要给字幕留出安全区，F 包看 `st.area`。

## 六 · 出处

- 形式的需求和取舍：2026-10-30 那轮「风格锁不锁」的结论（风格按账号锁，变化来自形式、动态、元素）。
- 动作语法借自 `video-shotcraft` 的六张镜头卡（value-stagger-gradient／radial-wave／before-after-slider-scrub／draw-svg-trace／bezier-source-converge-merge／glow-flyline-moves），**借动作不借皮**。
- 小样：`~/Desktop/ 复星财富/IFA宣传/口播成片_新形式小样_1031/`（数轴／汇聚／航线／链条到前后拉杆，带原声）。
