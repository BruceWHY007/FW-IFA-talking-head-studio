# B-roll 三路来源：用户给的 → 免费素材库 → AI 生成

顺序是优先级：**视频优先，图片次之，AI 生成最后**。但不是「本地优先到底」——本地够用就本地，不够或重复就去图库补，本地与图库混着用没问题，归一化会把它们压成同一支片子。
**同一段素材一条片子里最多用 2 次**（完整版第 3 次 `build.py` 直接停）。本地素材不够就去免费素材库按 §二 的画面词找，**不要为了「用本地素材」把同一条剪三次**。

## 零、选素材的推导链（先读这一节，10-30 按 Claude 定稿与 DeepSeek 复现对比写成）

**同样的素材库，Claude 选得准、DeepSeek 选得偏，差别不在搜索，在搜之前和搜之后的两步。**

### 五步，顺序不能反
1. **这句话有没有能拍到的东西？** 地点（香港、中环、内地城市）、实物（钱、手机行情、住宅、保单、货轮）、动作（签单、开户）。`beats.py` 标「实物」的句子才算；标「比喻」的只在这句就在讲那个概念时才借画面。**没有就不配 B-roll**——让清单卡、金银整行、插条去扛。
2. **写 `see`：观众应该看到什么**，中文、具体到地点或物件：「中环中银大厦与连廊，白天」，不是「香港」「金融」。写不出具体的，回到第 1 步。
3. **按 `see` 写 `q`**：地域＋实物＋状态的英文场景词（`hong kong central bank of china tower day`），一个镜头两三个词，按优先级排。
4. **看候选表挑，不收第一个**：完整版 `stock.py plan` 每镜一张 16 格候选图，**对着 see 挑最像的那格**；极简档 `stock.py auto` 给的只是「第一个没有字／脸／暗角标的」，审片时对着 see 判，不像就 replace，换 `q` 或去 `plan` 看全部候选。
5. **放回上下文复核**：亮度（不低于人脸镜一半）、可读字（假报价、外文招牌）、版式（白底别用光晕圆、横版走画框条）、前后不同类、入点避开闪动。

### 正例：Claude 定稿（49 号令，12 条全部按这条链来）
| 原话 | see（观众看到） | 为什么选它／换掉了什么 |
|---|---|---|
| 它管的不是企业，是你我这样的个人 | 香港街头电车与人流，三条分带 | 「个人」＝街上的普通人；三条同题材画面做分带 |
| 发改委公布了对外投资管理办法 | 新华网答记者问原文，荧光带扫那句 | 政策有原文就用原文截图，不用「桌上的文件」 |
| 现在是要真掏钱 | 点钞特写，三条分带 | 「掏钱」就是钱；入点挪到 4.8s 避开亮度闪 |
| 二级市场理财照旧 | 中环中银大厦与连廊，白天 | 原先的行情数字墙太暗（YAVG 45）、有可读假报价 → 换掉 |
| 境外券商直接开户炒港股美股 | 手机上的券商行情界面 | 「开户炒股」＝手机 App；界面里的英文是本意（text_ok） |
| 境外买房理论上要备案 | 住宅楼群 | 「买房」＝楼；不是「海外」「货轮」 |
| 再说香港保险 | 维港与国金，满幅 | 换段落用地标，告诉观众「到香港这一块了」 |
| 必须在香港签单 | 香港街景，方窗 | 地点要真 |
| 关键是成本，和结构锁没锁死 | 白色建筑线条（比喻） | 这句就在讲「结构」才借比喻；白底上光晕圆糊，改方窗 |
| 不是不让你出海，是让你带着账本出海 | 货轮出海 | 「出海」字面就有画面 |

### 反例：DeepSeek 复现（10-29／10-30，同一套素材库）
| 原话 | 它配的 | 错在哪一步 |
|---|---|---|
| 材料造假，就要没收违法所得 | 地上的金属环 → 外国护照 | 第 1 步：这句没有能拍的东西，该用金银整行；第 3 步 q 写成字符串被逐字搜 |
| 不在本办法管辖范围里 | 街舞 → 铁丝网 | 第 1 步：抽象句硬配画面 |
| 信托有没有构成实质控制 | 递钥匙 → 码头系船柱 | 第 1 步＋第 4 步：没有 see，审片时只问「能不能用」 |
| （76 号片，十几句） | 先下 3 条通用香港素材，再分给各句，一条天际线用 5 次 | 第 2–4 步全跳：素材先行、句子后配 |
| 这类标准化通道不用核准 | 夜景维港（接白天室内亮度差 64） | 第 5 步：自动提醒写着亮度差，照样放行 |
| 审片 6 条 | 一次全写 keep、理由「复审通过」 | 第 4 步：没对着 see 看图（现在理由 <8 字 build 直接停） |

**一句话：先替这句话决定观众该看到什么（see），再去找；找来的东西对着 see 判，不对着「能不能用」判。**

## 一、用户给素材（最优先）

```bash
python3 scripts/broll_index.py <工程> <素材目录> [<目录2> ...]
```
每条素材抽 4 帧拼一行，标编号（L001…）、时长、横竖、分辨率、运动量 → `broll/lib_sheet_NN.jpg`。
**看图挑，不看文件名**：文件名写的是当初的用途（「C03 · 格子里的第七年」），不是画面里有什么。

挑片的五条判据（按顺序）：
1. **信息对得上**：这句话说的那个东西／那个地方／那件事，画面里有没有。对不上至少「气质对」（参考片：摩根士丹利 → 西装男看手机）。**不能对着干**（说「放心」配一张焦虑的脸）。
2. **不误导**：B-roll 里出现具体地点、品牌、人物时，观众会当真。画面不是她本人办公室／孩子学校时，标注签只写泛指（「中环」），不写「我的办公室」；facts.json 里注明「示意」。
3. **竖版能用**：竖版素材直接满幅。横版素材有两种用法——主体在中间、裁出 9:16 不丢东西 → `fit: cover` 加 `focus`；主体占满宽度（教室、会议桌、天际线）→ `fit: band` 画框条。
   ⚠️ **1920×1080 的横版裁竖版只剩 607 像素宽，放大 1.8 倍会糊**（build.py 会报）。能用 4K 源就用 4K；不能就优先 band，或只给「暗下来做底」的镜头用（大字卡底、照片卡底）。
4. **有动作**：B-roll 里有人就要有动作（走、写、递、笑）；站着不动的人像贴上去的。没有人的空镜要有镜头运动或环境运动（车流、水面、光）。
5. **够长**：镜头要多长，素材从入点起就要有多长。不够时最多慢放到 0.85 倍（再慢就是慢动作，判为不协调），再不够就换素材或缩短镜头。

用户给了**出镜人自己的素材**（办公室、见客户、活动现场、孩子上学）时，单独建一个目录索引，优先配给第一人称句（S 类）。这是全片可信度最高的镜头。

## 一·五、素材要「换类」，不只「换条」

搜「signing document close up」会给你一屏「手在写字」；搜「office desk paperwork」还是手。**只换条不换类，成片照样单调。**
挑素材时按画面主体分类：**人（走动、会议）／手（签字、翻页）／建筑（楼群、天际线）／文件（摊开的纸、信封）／物件（钥匙、手机）／空镜（海面、光）**。
两条相邻的 B-roll 不能同一类；一支 3 分钟的片子里，手部特写最多 2 条，建筑／空镜要占一半以上，人要有动作。

搜索词按**场景**写，不按动作写：✗ `signing document close up`（全是手）✓ `hong kong street tram`、`office window city view`、`documents on desk wide`。

## 二、免费商用量素材库（五个源）

```bash
python3 stock.py <工程> sources                        # 看有哪些源、许可、能不能用
python3 stock.py <工程> search "hong kong street tram" --source all
python3 stock.py <工程> get mi:4959 st_office_person   # mi=mixkit，co=coverr，pe=pexels
```

| 源 | 画质 | 许可 | 适合 | 拿法 |
|---|---|---|---|---|
| **Pexels** | 1080–2160p | Pexels License，免费可商用、无需署名 | 主力源；港景、亚洲面孔、城市空镜最多 | 搜索页走 firecrawl（直连被拦），视频直连下载 |
| **Coverr** | 1080p | Coverr License，免费可商用、无需署名 | 欧美生活场景、干净的室内与城市空镜 | CDN 直连，不用 key |
| **Mixkit** | 最高 720p | Mixkit Free License，免费可商用、无需署名 | 办公、自然、明亮的空镜 | CDN 直连，不用 key |
| **Pixabay** | 1080p／4K（脚本自动选 ≤1920 宽那档） | Pixabay Content License，免费可商用、无需署名 | 片库最大，欧美场景多，港景有但几乎都是横版 | 官方 API，key 只放环境变量 `PIXABAY_API_KEY` |
| **Internet Archive** | 不定 | 只收明确标了 CC／公有领域的条目（`licenseurl` 里带 creativecommons 或 publicdomain） | 历史影像、政府片、纪录片素材；**当 B-roll 用质量普遍不够**，偶尔能补到别处没有的镜头 | 无 key，公开 API |

- 一次搜 2–3 个词组，`--source all` 会把五个源的结果拼成一张缩略图总图，编号前缀 `pe:`（Pexels）／`co:`（Coverr）／`mi:`（Mixkit）／`px:`（Pixabay）／`ia:`（Archive）。
- 默认只要竖版（缩略图量画幅过滤）；横版加 `--landscape`。
- 下载后一律 `ffprobe` 复量一次：搜索页写的分辨率常常不是真的（07 #32）；Coverr 的 2160p 会回 404，只取 1080p 及以下（脚本已按 range 探真）。
- 登记在 `broll/stock/stock_picks.json`：`source`、`page`、`licence` 一并写入，交付时能逐条说清出处。
- 局限照旧：香港本地场景（港校、港铁、街市、维港某一角）免费库里少；对不上的宁可拍或生成。

### 不要抓的两类

- **抖音／小红书／B站／YouTube 上别人的成片、影视片段、品牌广告**：这条片子是发在公开账号上的，不属于「个人自己看」。风险有三层，版权只是第一层，更常见的是平台判重（搬运）限流、被原拍摄者或品牌方投诉、以及撞上本 skill 自己的红线（不用陌生人的正脸和品牌冒充当事人）。技术上 yt-dlp 能下，但不进流程、不写进 skill。
- **带水印、带台标的素材**：哪怕拿到 1080p，进片就是事故。

要「网上任意视频」那种自由，正确的做法是：让本人补拍（手机横着拍几秒就够）、或走 AI 生成（`gen_providers.json` 里接渠道，默认关闭、花钱前先报数）。

## 二·五、图片也能当 B-roll（政策、数据、原文最适合）

视频素材库里找不到「一纸公文」「一张报表」的时候，用**图片 + 运镜**比硬配视频强：

```bash
python3 stock.py <工程> images "official documents"                        # 免费商用图片（Pixabay 图片 API）
python3 stock.py <工程> search "National Development and Reform Commission" --source wiki   # Wikimedia，CC／公有领域，高清
python3 stock.py <工程> get wk:94292780 img_ndrc                          # 存到 broll/img/，带许可与署名
# decompose 里直接写图片，运镜和视频同一条相机曲线（push／pull／pan-l／pan-r／hold）
{"id": "B36", "type": "B", "cover": "第三，罚款硬了", "image": "broll/img/xxx.jpg", "move": "push"}
```

- 图片会自动 cover 进画面窗、加统一调色（saturate 0.94 / contrast 1.04）和网点，和视频混在一支片子里不跳。
- `build.py` 会量图片尺寸：短边 <1080 报警（放大到 1080 会糊），这时改 `move: hold` 或换大图。
- **四个来源，按顺序用**：① 官方原文／公告的截图（要什么有什么，还有权威感）② 自己的照片（办公室、文件、屏幕、合影）③ **Wikimedia Commons 搜相关信息**（政府大楼、机构、地标、签署现场，CC 或公有领域，能到 2000–6000 像素）④ Pixabay 图库图。图库随机图（邮票、旧信、白底产品）**大多不对题**，别为了有画面上这些。
- **CC BY-SA 这类要求署名**：`stock.py` 会把 `credit` 写进时间线，交付清单里列一条；发布时把署名放进描述或评论区。
- 截图里的可读文字要和屏上事实一致；涉密或客户信息先打码。

## 三、AI 生成（默认关闭，需要的人自己接入）

```bash
python3 scripts/gen_video.py <工程> providers          # 看配置里有哪些渠道、启用没有、密钥在不在（只报有无，不显示值）
python3 scripts/gen_video.py <工程> plan [--backup]     # 出提示词卡 broll/gen/cards.md（--backup：有素材但写了 gen_prompt 的也出卡当备选）
python3 scripts/gen_video.py <工程> run --yes           # 真调用（三个前提齐了才会调）
```
**渠道不写死**。`template/gen_providers.json` 是一张配置表，预留了这些位，全部默认关闭：

| 渠道位 | 状态 | 说明 |
|---|---|---|
| `runninghub_app` | 端点与写法取自本机《向光而行》项目跑通的做法 | RunningHub「AI 应用」通道（`/task/openapi/ai-app/run`＋webappId＋nodeInfoList）。普通级 key 调不了标准模型接口（错误码 1014）时走这条。预填的是「Seedance 2.0 Fast 全能生视频」应用的节点号 |
| `runninghub_workflow` | 端点与字段按官方文档核对 | 自建 ComfyUI 工作流通道（`/task/openapi/create`＋workflowId）。nodeId／fieldName 每个工作流不同，要自己填 |
| `seedance` | 按火山方舟官方文档核对（2026-10-22） | 方舟直连，`doubao-seedance-2-0-fast-260128`，ratio 9:16，duration 4–15 |
| `minimax` | 只核对了建任务 | 海螺文生视频没有竖版参数，出 16:9 后走 band |
| `kling` | 未核对 | 可灵要 AK/SK 现签 JWT，脚本已支持 `auth: kling_jwt` |
| `fal` | 未核对 | 一个 key 调多家模型，海外账号适用 |
| `custom` | 空白 | 照任一渠道的结构填 |

接入一个渠道＝三步：把配置复制到 `~/.config/ifa-koubo/gen_providers.json`（个人默认）或工程根目录（只这个工程用）→ 该渠道 `enabled: true`、`active` 写它的名字 → 把密钥放进环境变量（`key_env` 写的名字）。**密钥永远不写进任何文件**。
通用执行器支持「建任务 → 轮询 → （可选）取结果地址 → 下载」的异步接口和同步接口；网络抖动自动重试；大文件下载不走本地代理。

**花钱前必须停**：`plan` 出来的条数、总秒数、按该平台当日价格估的费用，报给用户，用户点头才加 `--yes`。
没有接入任何渠道时，`cards.md` 就是交付物——用户拿去即梦、可灵、海螺、RunningHub 网页手动生成，文件命名为 `<镜号>.mp4` 放进 `broll/gen/`，build.py 自动接上（`pick: "gen:B07"`）。

### 生成 B-roll 的提示词怎么写

脚本会在每条提示词后面自动加统一的尾巴（竖屏 9:16、主体在中央 60%、写实自然光、缓慢推近、**无任何文字／logo／可读招牌**、人物只出现背影侧影手部）。正文只写这一镜要的画面：
- **一个主体、一个动作、一个环境、一个光**：「清晨，母亲牵着穿校服的女儿走在香港半山的斜坡人行道上，背影，书包轻晃，阳光从楼缝斜照」
- 写具体名词，不写形容词（形容词＝AI 味）；写「背影／手部」，不让模型画正脸（出镜人只能用实拍，路人正脸容易崩）
- 时长按镜头需要＋0.5 秒余量；渠道的时长下限（Seedance 2.0 是 4 秒）比镜头长时，进片只截用中间一段
- 更细的平台写法交给 `seedance-20`（Seedance）／`cinematic-video-prompt-engineer`（通用）

## 四、照片卡（P）的图从哪来

真实人物、机构、新闻的照片：优先官方来源（机构官网、新闻稿、本人授权），在 `credit` 写图源；新闻照片有版权，**对外发布前要确认能用**，交付说明里列出来。
App 界面、文件：用真截图，敏感信息先打码。找不到真图就不做 P，改成 B＋字幕扛信息，**不画假图冒充证据**。
