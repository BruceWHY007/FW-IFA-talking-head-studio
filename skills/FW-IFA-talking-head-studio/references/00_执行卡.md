# 00 · 执行卡（任何模型先读这一页；照着做，不要跳步）

> 给执行者的一页纸：每一步只有「命令 → 必须看的东西 → 过不去的条件」。细节按需跳到 `13_完整复现手册.md` 对应的节。
> 这一页是 2026-10-30 按 DeepSeek 复现实测改出来的：上一轮它只读了手册开头就开工，自创画面、拷别人的分镜、批量放行审片——下面每条「禁止」都是那一轮真发生过的。

## 先记住五条

1. **完整版 ≥ 极简档。** 两档区别是「谁来判断、谁挑素材、谁来审」，不是镜头少、信息少。完整版从极简档的自动底稿升级，只加不减。
2. **不自创画面类型。** 能用的只有：A 人脸／B B-roll（9 种 layout）／G 大字卡／I 信息卡（compare／list／timeline／chart／quote）／texts 屏上字（step／stack／scatter）／tracker 进度坞／inserts 插条／captions.gold·silver 金银整行。没有能拍的实物时，「代码画面」就是 I／G／texts／tracker——不要另写动效组件。
3. **锚点写句号。** `"cover": "s17"` 或 `"s16–s19"`，`at`、`until`、`from` 也一样。句号在 `work/beats.md`。别凭印象抄原话。
4. **不改技能本体。** 只改工程里的文件（decompose／edits／facts／transcript）。觉得技能有 bug：写进交付里的「建议」，不要直接改 `~/.agents/skills/IFA口播成片/`。
5. **一条片子一次会话。** 上下文太长时你会只读开头、赶着收尾；宁可停下来交接，也不要「时间太长了，先这样」。

## 完整版升级（6b 的 `_待升级` 逐条做，build 会查）

门槛按片长折算，`beats.md` 顶部写了这条片子的具体数字。常见缺口和做法：

| build 报的缺口 | 怎么补 | 例 |
|---|---|---|
| 金银整行不够 | `captions.gold`／`silver` 加最硬的判断，写成字幕里**连着的一段原话**（4–12 字） | 「现在是要真掏钱」 |
| 屏上字不够 | 「第一／第二」→ `texts.step`；列 3 项 → `texts.stack`（`num:true`）；两三个关键词 → `texts.scatter` | 投资者三类：企业／其他组织／居民个人 |
| 画面处理种类不够 | B-roll 换 layout：`pip` 方窗、`glow` 光晕圆、`ring` 细环、`band` 画框条（横版素材）、`bands3` 三条分带、`glowband`、`doc` 原文页 | 白底素材别用 glow |
| 插条为 0 | `inserts: [{"pos": "bottom", "cover": "s12–s13", "pick": "stock:…"}]`，放在人脸段上 | 她讲备案时下半屏放文件特写 |
| 信息卡为 0 | 两个数／两套体系 → `compare`；时间先后 → `timeline`；原话金句 → `quote` | 发改备案 vs 外汇购付汇 |
| 进度坞缺 | 口播有三处以上「第一／第二…」：`tracker` 写标题和每格 2–4 字 | 四个变化：个人入列／事前报告／罚款变硬／豁免清单 |
| 原文页缺 | 第 8 步 webshot，`layout: "doc"` | 新华网答记者问 |
| why 不全 | 每一镜一句话：这条画面在这句里指什么 | 「真掏钱」→ 点钞特写 |
| see 不全 | 每条 B-roll 写观众应该看到什么，具体到地点／物件 | 「中环中银大厦与连廊，白天」，不是「香港」 |

某一项这条片子**确实**用不上：`"waive": {"inserts": "全片 40 秒，人脸段都短于 6 秒，插条没地方放"}`（理由 ≥8 字，交付时列出来）。`waive` 不是绕过检查的开关——评审会看理由。

## 禁止（上一轮真发生过）

- 从别的工程拷 `decompose*.json`／`edits.json`／`facts.json`／`broll/` 当自己的判定。复现测试里尤其不许。
- 审片表批量写 keep、理由写「通过／复审通过」。
- 先下几条通用素材（「香港天际线」「街景」）再分给各句；一条素材用 3 次以上。
- 给没有能拍的东西的句子硬配画面（「不在管辖范围里」配铁丝网、「实质控制」配递钥匙）。
- 自己给 numcheck 报的数字标 `num_verified`。
- 只校对一部分句子就写分镜。
- 改技能里的 `build.py`／`fullbleed.tsx`／`SKILL.md`。
- 自创 `layout`（例如 motion）或数字递增计数动画（规矩是「数字不 count-up」，数字在开口帧落定）。
- `--draft` 出的片子拿去交付（draft 只给自己看结构）。

## 数据格式（写错 build 会自动纠一部分，但别依赖它）

- `q`（检索词）是**列表**：`"q": ["hong kong central skyline", "ifc tower"]`。
- 信息卡 `items` 是**对象**：`[{"t": "QDII"}, {"t": "港股通"}]`；compare 用 `label／value／unit／note`。
- `title` 必填：`{"series": "跨境合规笔记", "episode": "钱出海之前先看这四条"}`——F 包没有封面，第一帧的刊头就是标题。
- 每条 B-roll：`"see": "中环中银大厦与连廊，白天"`（先写）→ `"q": ["hong kong central bank of china tower day", …]`（按 see 写）。
- 检索词规则：地域＋实物＋状态（`hong kong` 打头），讲内地／香港不用外国国旗、政府楼、外文招牌。
