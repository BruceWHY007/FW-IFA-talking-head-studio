# 12 · 极简档（F-lite）

同一套 F 满幅讲述的字体、金银字、刊头、字幕、数字卡，**省掉判定和素材两步**，给「要快、要省 token」的场景。

| | 完整版 | 极简档 |
|---|---|---|
| 判定 decompose | 人工逐镜写 | `scripts/lite_plan.py` 自动生成（不调模型） |
| 画面 | 人脸＋B-roll＋小窗＋分带＋信息卡＋进度坞 | 满幅人脸＋数字卡＋步骤标题（第一／第二）＋金银整行＋关键词变金 |
| 素材 | 检索／AI／截图 | 不找；要补的地方只出 `tips`（可选） |
| 风格目录 | 文字菜单（见 SKILL.md §0） | 同左 |
| 验收 | qa 27 项＋评审子代理 | `qa.py`，只看响度、字幕对位、对比度；不派评审 |

流程：`ingest → analyze → trim` → `python3 scripts/lite_plan.py <工程> --series … --episode …` → `build.py <工程> --decompose <工程>/decompose_lite.json` → `render.py <工程>` → `qa.py`。
自动规划：每句取第一个「数字＋单位」做数字卡（≤6 张、间隔 ≥14s）；「第一／第二」做步骤标题；连续 10 秒无版面事件的空档里挑一句短分句整行换金／银。`decompose.lite=true` 时 build 不查「人脸占比」。
已知局限：人脸占比约 96%，节奏全靠字；没有 B-roll，信息密度高的政策类内容建议用完整版。
